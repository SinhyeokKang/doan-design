# thread-polish — 스레드 다듬기 묶음

## 사용자

- 사람: 캔버스 대화 패널, 프로젝트 Overview, 프로토타입 창에서 대화 스레드를 읽는다. 네 가지 모두 사람이 보는 화면만 바꾼다.
- 에이전트: 바뀌는 것이 없다. handoff 메시지 본문, CLI 출력, 대화 기록 형식은 그대로다.

## 문제

1. 캔버스 카드의 Open은 채움 없는 trigger 버튼이라 카드 안에서 버튼으로 잘 읽히지 않는다.
2. 스레드 코드 블록의 Copy가 성공해도 아무 표시가 없다. 실패할 때만 답 아래에 안내가 뜬다.
3. handoff를 받은 대화의 첫 메시지가 캔버스 카드와 같은 모양(배너, 머리 행, 구분선 아래 본문)이다. 내보낸 쪽 카드와 받은 쪽 메시지가 비슷하게 보이고, 받은 쪽에서는 카드가 무겁다.
4. Jump to latest가 너무 자주 뜬다. 지금은 사람이 휠을 조금만 굴려도 따라가기가 바로 끊기고, 바닥 24px 안으로 돌아와야 다시 붙는다(PRODUCT §5 'Follow'). 그래서 살짝 건드린 뒤 답이 자라면 바로 뜬다.

## 확정한 결정

- 캔버스 카드의 Open은 디자인 시스템의 `subtle` 버튼(회색 채움 캡슐, sm)이다. 지금 handoff 카드도 같은 규칙을 쓰지만, 3번에서 handoff 카드가 없어진다.
- Copy code가 성공하면 공용 토스트가 "Copied code"를 띄운다. 실패는 지금처럼 그 답 아래의 안내("Couldn’t copy the code. Select it and copy it yourself.")로 둔다.
- 받은 handoff는 사용자 턴 자리의 **에이전트 입력 버블**로 보인다.
  - 사용자 버블에 작성자 타입이 생긴다. 에이전트 입력도 사람 입력과 같은 버블(버디 accent-subtle 채움, 최대 80%)이다. 둘은 메타 줄로만 구분한다.
  - 에이전트 입력 버블은 안쪽 위에 메타 한 줄을 두고, 그 아래 구분선, 그 아래 본문(Markdown)을 둔다. 메타는 `forward` 아이콘, 출처 종류 아이콘과 이름, 상대 시각, Open이다. "From"은 화면에 쓰지 않고 스크린 리더에만 읽힌다(80% 폭에서 이름이 들어갈 자리를 남긴다). Open은 `panel` 버튼이다(색이 있는 채움 위에서도 흰 채움이 보인다).
  - 출처가 없어지면 지금 카드처럼 Open을 숨기고 이유를 붙인다("No longer in <project>", "Conversation deleted").
  - 내보낸 쪽(source thread)의 캔버스 카드는 그대로 카드다.
  - 지금 에이전트 입력은 handoff뿐이다.
- 따라가기를 관대하게 바꾼다. 바닥에서 **따라가기 거리**(스레드 스크롤러 높이의 1/3, 최소 120px) 안에서는 사람이 스크롤해도 따라가기가 이어진다. 그 거리를 넘게 올라가야 끊기고, 다시 그 거리 안으로 돌아오면 붙는다. Jump to latest는 따라가기가 끊긴 동안 그 거리 밖에서 새 내용이 생길 때만 뜬다.

## 완료 조건

- 캔버스 카드의 Open이 모든 상태에서 `subtle` sm 버튼으로 그려진다(캔버스 패널, Overview, 프로토타입 창).
- Copy code가 성공하면 "Copied code" 토스트가 뜬다. 캔버스 패널, Overview, 프로토타입 창에서 모두 그렇다. 실패하면 토스트 없이 지금의 안내가 뜬다.
- handoff로 시작한 대화의 첫 메시지가 에이전트 입력 버블로 그려진다. 메타는 한 줄을 넘지 않는다. 좁아지면 출처 이름이 먼저 3em까지 잘리고, 다음으로 사라진 이유 문구가 잘린다. 스레드 폭이 275px 미만(버블 약 220px 미만)이면 시각을 숨기고 이름의 tooltip에 남긴다. Open은 잘리지 않는다. 옮겨 온 직후 포커스와 스크롤은 지금 카드와 같은 규칙을 따른다.
- forced colors에서 에이전트 입력 버블의 가장자리가 보인다(사람 버블의 기존 규칙을 같이 쓴다).
- 바닥에서 따라가기 거리 안의 휠·키·스크롤바 이동 뒤에는 Jump to latest가 뜨지 않고, 손을 놓으면 따라가기가 바닥으로 돌아간다. 거리 밖으로 올라간 뒤 새 내용이 생기면 지금처럼 뜬다.
- 드래프트 `.doan/canvases/thread-polish.html`과 구현이 맞는다(`/design-sync`).

## 비목표

- 사용자 버블 안 Markdown을 사람 입력에도 적용하지 않는다. 사람 입력은 지금처럼 평문이다.
- handoff 말고 다른 에이전트 입력(에이전트 간 메시지 등)은 이번에 만들지 않는다.
- 내보낸 쪽 캔버스 카드의 모양은 Open 말고는 바꾸지 않는다.
- Jump to latest의 위치와 모양은 바꾸지 않는다(answer-popover가 자리를 옮긴다).

# revision-continuity — 에이전트가 수정하는 동안에도 리뷰가 끊기지 않게 한다

근거: [ux-audit-261025-2 보고서](../ux-audit-261025-2/report.md) L-2, L-4, L-13, L-17, 가설 T-11과 W-9. 원 근거는 `.scratch/ux-audit/loop-261025-2/`(S2 #7–#17, S3 #6–#7)에 있다.

## 사용자

- **사람**: 앱에서 캔버스를 보고 댓글을 쓰는 사람이다. 에이전트가 같은 프로젝트의 파일을 고치는 동안에도 계속 리뷰하고 다음 피드백을 쓴다.
- **에이전트**: 직접 바뀌는 것은 없다. 다만 에이전트가 캔버스를 옮기거나 같은 프로젝트의 다른 파일을 고쳐도, 사람의 리뷰와 `doan active`의 대상이 유지된다.

## 문제 (관찰한 사실)

1. **쓰던 새 댓글이 저장 불가가 된다(L-2).** 새 댓글을 쓰는 중에 `design/` 아래 **어느 파일이든** 바뀌면 열린 캔버스가 다시 로드된다. 그러면 편집기에 "Original document or target is unavailable."가 뜨고 Save가 영구히 비활성이 된다. 남는 길은 Cancel이나 Discard로 버리는 것뿐이다. 관찰한 경우는 열린 캔버스와 무관한 `account/profile.html` 변경이었다(S2 #9–#13). 메시지는 원인(캔버스가 다시 로드됨)을 말하지 않는다.
2. **캔버스 파일 이름이 바뀌면 리뷰에서 밀려난다(L-4).** 에이전트가 열린 캔버스 파일을 옮기거나 이름을 바꾸면, id가 같아도 "<title> was removed from design/" 토스트가 뜨고 Overview로 돌아간다. 선택은 지워지고 초안은 막힌다(S3 #6). 다시 열면 댓글은 id를 따라 그대로 있다(S3 #7).
3. **사람이 고른 Canvas 범위가 되돌아간다(L-13).** 요소를 선택한 채 Comments 범위를 Canvas로 바꿔도, 에이전트가 캔버스를 저장하면 Selection으로 돌아간다(S2 #7→#8).
4. **바뀌는 것이 없는데 저장 확인이 뜬다(L-17).** 선택이 없고 초안이 열린 상태에서 Esc(또는 빈 여백 클릭)를 누르면 "Save your comment first?"가 뜬다(S2 #15).
5. **(가설) 리로드 중 위치 정보가 사라져 보인다(T-11, W-9).** 리로드하면 앵커 스냅샷이 비워진다. 새 문서가 응답할 때까지 모든 프레임·요소 댓글이 "Location unavailable"로 표시되고, 핀이 사라지며, Selection 목록이 빈다(코드 추적). 실제 화면에서 보이는 시간은 관찰하지 못했다. 폭이 없는 캔버스에서는 이 상태가 계속된다(코드 추적).

## 완료 조건

- 새 댓글을 쓰는 중에 열린 캔버스가 다시 로드되면, 편집기가 원인("The canvas reloaded while you were writing.")을 말한다. **Start again on this version**을 누르면 같은 범위(Canvas 또는 현재 선택)로 새 초안이 시작되고, 쓴 본문이 그대로 남으며, "To:"가 현재 대상을 보인다. 그 초안은 저장할 수 있다.
- 선택 범위로 다시 시작할 때 현재 선택이 없으면, 버튼은 비활성이고 "Select a target in the canvas, or switch to Canvas."를 보인다. 본문은 남는다.
- 열린 캔버스가 실제로 불러온 파일과 무관한 `design/` 파일이 바뀌면, 열린 캔버스를 다시 로드하지 않는다. 쓰던 새 댓글, 선택, 핀, 뷰가 그대로다.
- 열린 캔버스 파일이 옮겨지거나 이름이 바뀌고 같은 프로젝트에 **같은 canvas id를 가진 캔버스가 정확히 하나** 있으면, 앱은 그 캔버스를 계속 연다. 토스트와 Overview 이동이 없고, 뷰(배율·위치)를 유지하며, 선택을 다시 앵커한다. 댓글 목록과 범위·상태 필터를 유지한다. 편집 초안은 유지된다. 새 댓글 초안은 문서가 바뀌므로 위 "다시 시작" 경로를 따른다. `doan active`는 새 경로를 돌려준다.
- 같은 id의 캔버스가 없거나 둘 이상이면 지금과 같이 처리한다. 다만 같은 id 행이 둘 이상이면 토스트는 "removed"라고 하지 않는다.
- 재시작할 때 저장된 경로가 없더라도, 저장된 canvas id를 가진 캔버스가 하나 있으면 그 캔버스와 뷰를 복원한다.
- 사람이 고른 Comments 범위(Canvas/Selection)는 같은 대상의 재앵커(리로드, 캔버스 이동)에서 바뀌지 않는다. 선택한 대상이 실제로 다른 노드로 바뀔 때만 지금처럼 Selection으로 맞춘다.
- 선택과 재앵커 대기가 없을 때 Esc나 빈 여백 클릭은 초안 대화상자를 띄우지 않는다.
- 리로드 중(새 문서의 앵커 응답 전)과 렌더된 문서가 없는 상태(폭 없음, 로드 실패)에서는 "Location unavailable"을 표시하지 않는다. 런타임에서 깜빡임이 재현되지 않으면 이 항목은 측정 결과만 기록하고 닫는다(tasks 1).

# Doany V2 — Pebble

## 확정한 방향

사용자가 선택한 V2는 최초 **Pebble**이다. Pebble-D, D-shape와 그 후속 수정본은 채택하지 않는다. Git 브랜치를 새로 만들지 않는다. 같은 `doan-mascot` 캔버스에서 V2를 명확하게 구분하고, V1 원본·모션·탐색 시안은 보존한다.

- 선택 원본: [V2 정지 이미지](../../../.doan/assets/doany/v2/doany.png).
- 원본과 바이트가 같은 탐색 이미지: `.doan/assets/doany/shape-study/pebble.png`.
- SHA-256: `42346ecd5e16cd421bbfffc17d04826f278495f8997cd62564dd6e67d09e6e9c`.
- 캔버스: [doan-mascot.html](../../../.doan/canvases/doan-mascot.html), `doany-v2-home`, `doany-v2-welcome`, `doany-v2-selected`, `doany-v2-motion-spec` 프레임.
- V2 전용 에셋: `.doan/assets/doany/v2/`. V1의 `transparent/`, `motion/`, `white/`, `simple/`을 덮어쓰지 않는다.

## 사용자와 문제

Home과 Welcome을 보는 사람이 대상이다. 사용자는 기존 여섯 갈래 Doany가 Codex 로고와 닮았다고 판단했고, 여러 시안 중 Pebble을 선택했다. 이 판단은 외부 로고 유사성 검증 결과가 아니라 이번 교체의 사용자 요구이다.

## 외형

비대칭 조약돌처럼 이어지는 한 덩어리 몸통, 넓고 둥근 아래쪽, 좁아지는 위쪽 어깨, 보라색 털 질감, 간격이 있는 검은 타원형 눈 두 개, 오른쪽 위로 기울어진 검은 베레모를 유지한다. D 형태, 구멍, 팔다리, 입을 추가하지 않는다. 선택 이미지를 다시 생성하거나 색을 바꾸지 않는다. 모션용 레이어를 만들 때도 선택 원본을 기준으로 복원한다.

## 적용 범위

기존 [PRODUCT §5 Doany](../../PRODUCT.md) 계약을 이어받는다. Home·Welcome의 정지 이미지와 모션, 패키지 앱 아이콘, Doany DS 참조를 V2로 맞춘다. V2 앱 아이콘은 선택 원본을 흰 배경에 합성한다. 단순화 SVG와 favicon은 V2 Pebble로 그 자리에서 교체한다. 화면 구조·문구·슬롯·키보드 동작은 바꾸지 않는다. 별도 신규 마스코트 화면, 애니메이션 엔진, 외부 의존성은 추가하지 않는다.

현재 문서는 구현 전 명세이다. V2 정지 원본·몸통·베레모 텍스처와 같은 캔버스의 실행 Home·Welcome 초안이 준비되어 있다. 앱 적용과 패키지 아이콘은 아직 만들지 않았다.

## 완료 조건

1. Home·Welcome의 정지·모션·대체 이미지가 모두 선택 Pebble과 같은 외형이다. 로딩 전후 크기·눈 위치·베레모 위치가 튀지 않는다.
2. 호흡·깜빡임·시선·입력 반응·홉의 기존 타이밍을 유지하면서 Pebble의 매끈한 윤곽과 질감이 유지된다. 여섯 갈래 가장자리 변형은 없다.
3. Home 114px, Welcome 142.5px 슬롯과 기존 레이아웃을 유지한다. 홉의 정점에서도 베레모와 몸통이 잘리지 않고 입력 중 컴포저가 움직이지 않는다.
4. 클릭·Enter·Space와 실제 Home 전송 시작에서 홉한다. 거절·대기·빈 전송은 홉하지 않는다. 반복 입력은 기존처럼 홉 시점을 다시 시작한다.
5. reduced motion에서는 정지한다. 숨겨진 화면에서는 시간 진행과 반복 draw를 멈추며, WebGL/텍스처 실패와 컨텍스트 손실에서는 V2 정지 이미지가 남는다.
6. StrictMode, 반복 Home 방문, 패키지의 file/asar 경로에서 누수·이미지 누락이 없다.
7. V2 런타임 증거를 새로 남긴다. V1 검증 결과나 정적 스토리보드를 V2 모션 검증으로 보고하지 않는다.

## 범위 밖

D 계열 시안 채택, V1 탐색 기록 삭제, 새 등장 연출·상시 튀기·음향·전송 완료 축하, 다른 화면으로 마스코트 확장, 새 공용 포맷·CLI 명령은 포함하지 않는다.

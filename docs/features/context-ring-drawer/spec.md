# 컨텍스트 링 서랍 — spec

## 사용자

- **사람**: 대화 중인 사람. docked composer의 컨텍스트 링을 눌러, 지금 대화의 컨텍스트 사용량과 그 대화 프로바이더의 사용량 창(5h, Weekly 등)을 한곳에서 본다. 대상은 오버뷰, 캔버스 대화 패널, 프로토타입 창 대화 패널이다.
- **에이전트**: 바뀌는 것이 없다.

## 문제 (관찰)

- docked composer tray 끝의 컨텍스트 링은 컨트롤이 아니다. 누를 수 없고 Tab 순서에도 없으며, hover 툴팁으로 컨텍스트 사용량 두 줄만 보여준다(PRODUCT §5 'Context window ring').
- 대화 중인 프로바이더의 사용량 창(5h, Weekly 등)을 보려면 헤더 오른쪽의 Agent usage를 열어야 한다. 그 popover는 연결된 모든 프로바이더를 보여주므로, 지금 대화와 관계없는 프로바이더까지 섞여 있다.

## 완료 조건

1. **링은 버튼이다**
   - 링은 지금처럼 컨텍스트 사용량을 보여준다. 값, 색 규칙, 갱신 시점은 그대로다.
   - 클릭, Space, Return으로 서랍이 열린다. Tab 순서에 들어간다.
   - 접근 이름은 지금과 같다("Context window 42% used · last turn"). 접근 설명도 같다(토큰 줄). 서랍이 열려 있는지는 `aria-expanded`로 알린다.
   - hover 툴팁(두 줄)은 그대로 남는다. 서랍이 열려 있는 동안은 툴팁을 띄우지 않는다.
2. **레이아웃이 바뀌지 않는다**
   - 링의 보이는 크기(16px)와 tray 안 위치, tray의 다른 요소 위치와 크기, tray 높이가 지금과 같다. `/design-sync`로 바꾸기 전과 후를 재서 확인한다.
   - 누를 수 있는 영역만 링보다 넓다. 그 영역은 보이지 않고 이웃 컨트롤의 영역과 겹치지 않는다.
   - hover와 pressed 표시는 tray의 다른 트리거와 같은 방식으로 하되, 레이아웃을 바꾸지 않는다(초안에서 정한다).
3. **링이 없으면 버튼도 없다**: 기록된 값이 없을 때(새 대화, 첫 턴 전, 링 이전의 턴, Cursor, 창 크기를 모르는 Antigravity 모델, status line으로 바뀐 composer)는 지금처럼 링도 버튼도 없다.
4. **서랍 내용**
   - 맨 위 Context: "42% used · last turn"과 "84K of 200K tokens"(링 툴팁과 같은 값과 문구 규칙).
   - 그 아래, 대화 프로바이더의 사용량 행: 헤더 Agent usage popover의 그 프로바이더 행과 같은 내용과 문구다("Updated …", 창마다 한 줄, "Limit reached …", "Reading usage…", "Couldn’t read usage…" 등).
   - Refresh usage 버튼: 헤더의 Refresh usage와 같다(사용 가능한 모든 연결을 읽고, 이미 도는 읽기에 합류한다).
   - 사용량 행이 없는 경우는 Context만 보여준다. 대상은 다음과 같다.
     - Antigravity(헤더에도 나오지 않는다)
     - 레거시 외부 대화. 그 대화는 사용자의 CLI 프로필로 돌므로, Doan 연결 계정의 사용량은 그 대화의 사용량이 아니다.
5. **읽기 규칙**: 서랍을 여는 것은 헤더 popover를 여는 것과 같은 읽기 시점이다. 같은 5분 규칙, 실패나 reset 뒤 즉시 읽기 규칙을 따른다. 값은 헤더와 같은 메모리 값을 쓰므로 두 곳의 숫자가 어긋나지 않는다.
6. **열고 닫기**
   - 서랍은 non-modal이고 링에 붙어 열린다. composer가 아래에 있으므로 위로 연다.
   - Escape나 바깥 누르기로 닫힌다. 닫히면 포커스는 링으로 돌아간다. 단, 바깥 누르기가 다른 컨트롤에 포커스를 줬으면 그쪽에 둔다.
   - 대화가 바뀌거나 링이 사라지면(예: 대화 삭제) 서랍도 닫힌다.
7. **프로토타입 창**: 프로토타입 창의 대화 패널에서도 같은 서랍이 열리고 같은 사용량을 보여준다(사용자 결정).
8. **헤더 Agent usage**: 지금과 완전히 같다.

## 범위 밖

- 링이 없는 상태에서 서랍을 여는 방법(사용자 결정: 지금처럼 없음).
- 사용량 행에서 Agent settings로 가는 링크. 헤더 popover에만 둔다.
- Refresh를 그 프로바이더만 읽게 하는 것. 지금 읽기 IPC는 전체 읽기만 있다.
- 서랍에서 대화 압축(compaction)이나 모델 바꾸기 같은 조작.
- Home composer(링이 없다).

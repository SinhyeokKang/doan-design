# github-star-prompt — spec

Doan을 쓴 지 어느 정도 된 사람에게 GitHub 저장소에 별을 달아 달라고 한 번 묻는 작은 카드를 보인다. 누르면 저장소 페이지를 브라우저로 연다.

## 사용자

- **사람**: 릴리스 빌드를 쓰는 사람. 팝오버를 보고 별을 달지, 지금은 넘길지, 다시 묻지 말라고 할지 고른다.
- **에이전트**: 바뀌는 것이 없다. CLI, 스킬, 가이드는 그대로다.

## 문제

- Doan은 공개 저장소(`https://github.com/SinhyeokKang/doan-design`)에서 배포되지만, 앱 안에서 저장소를 알리는 곳이 없다. 앱이 저장소로 보내는 길은 업데이트의 Release Notes ↗(릴리스 페이지)뿐이다(PRODUCT §5 item 0 'About').

## 동작

- **누구에게**: 업데이트를 확인하는 사본과 같은 조건의 릴리스 빌드(PRODUCT §5 item 0 'About' 'Updates': `/Applications` 또는 `~/Applications`에 직접 있고 translocate되지 않은 릴리스 빌드)에서만 보인다. 개발 실행, 로컬 패키지, tester 빌드에서는 보이지 않는다.
- **언제**(사용자 결정, 2026-11-13): 이 기기에서 성공으로 끝난 대화 턴(`turn.done`)을 센다. 센 수가 기준(처음 20)에 닿은 뒤, 턴이 끝나고 사람이 1.2초 동안 키 입력을 하지 않은 순간에 띄운다. 첫 실행(onboarding) 중이거나 모달·다른 팝오버·메뉴가 열려 있으면 띄우지 않고 다음 턴 끝으로 미룬다.
- **어디에**(사용자 결정): 앱 오른쪽 아래 토스트 자리의 카드. 자동으로 사라지지 않고 포커스를 빼앗지 않는다. 어느 화면에서나 같은 자리다.
- **내용**: 짧은 문구 하나와 버튼. 문구는 `/design-draft`에서 clarify 프리셋으로 쓴다.
  - `Star on GitHub`: 저장소 페이지를 브라우저로 열고 카드를 닫는다. 이후 다시 묻지 않는다. 브라우저가 열리지 않으면 Release Notes ↗와 같은 방식으로 실패 줄을 보인다.
  - `Not now`: 닫는다. 다시 묻기(사용자 결정): 첫 `Not now`면 기준을 2배(지금 수 + 40턴)로 늘리고 적어도 3일 뒤에 한 번 더 묻는다. 두 번째 `Not now`면 다시 묻지 않는다.
  - Esc는 `Not now`와 같다. 카드는 토스트처럼 바깥 누름으로 닫히지 않는다.
- **네트워크**: Doan은 GitHub에 아무 요청도 보내지 않는다. 별 개수를 읽지 않고, 사람이 실제로 별을 달았는지 알지 못한다. 브라우저로 페이지를 여는 것뿐이다(PRODUCT §3 Out of scope 5, ARCHITECTURE의 GitHub 토큰 규칙).
- **기록**: 보였는지, 어떻게 닫았는지는 이 기기의 앱 설정에만 남긴다. 저장소나 다른 기기로 가지 않는다.

## 범위 (사용자 결정, 2026-11-13)

PRODUCT §3 Out of scope 5("the web only serves as the download path")에 걸리지 않는다고 본다. Doan은 요청을 보내지 않고, Release Notes ↗처럼 브라우저로 링크를 열 뿐이다. 승격 때 Out of scope 5에 브라우저로 여는 링크는 사람의 방문이라는 문장을 더해 오해를 막는다.

## 참고: Orca의 별 요청

출처: 설치된 `/Applications/Orca.app` 1.4.257의 `app.asar`(minified `out/main/index.js`의 `starNag`, `out/renderer/assets/App-*.js`의 `StarNagCard`·`StarNagToastHost`), 2026-11-13에 읽음. 소스 저장소는 보지 않았다.
- 띄우는 때: 실행한 에이전트 수가 기준점에서 35 늘었을 때(카드), 온보딩을 마쳤을 때(토스트), 에이전트 작업이 끝나고 1.2초 동안 입력이 없을 때(한 번만).
- 띄우기 전에 `gh` CLI로 이미 별을 달았는지 확인한다. `gh`가 있으면 버튼이 사용자의 GitHub 인증으로 바로 별을 단다. 없으면 브라우저로 저장소를 연다.
- `Later`/`Dismiss`/브라우저 열기 뒤에는 3일 쉬고, 다음 기준을 2배로 늘린다. 직접 별을 달았거나 그만 묻기를 고르면 끝난다. 결과를 원격 측정으로 보낸다.
- Doan은 `gh` 확인·대리 별 달기·원격 측정을 가져오지 않는다(GitHub 토큰 규칙, Out of scope 5).

## 완료 조건

1. 조건을 만족한 릴리스 빌드에서, 성공한 턴이 20번에 닿은 뒤 턴이 끝나고 1.2초 동안 입력이 없을 때 카드가 보인다. 개발 실행, 로컬 패키지, tester 빌드에서는 보이지 않는다.
2. `Star on GitHub`는 저장소 페이지를 브라우저로 열고, 그 뒤 다시 보이지 않는다. 브라우저를 열지 못하면 실패 줄이 보이고 버튼이 재시도다.
3. `Not now`와 Esc는 카드를 닫는다. 첫 번째면 턴 40번을 더 쌓고 3일이 지난 뒤 한 번 더 보이고, 두 번째면 다시 보이지 않는다.
4. 첫 실행 중, 모달이나 다른 팝오버가 열려 있을 때는 보이지 않는다.
5. 카드가 떠도 포커스를 빼앗지 않고, 키보드로 닿을 수 있다(PRODUCT의 다른 조용히 열리는 팝오버와 같은 규칙).
6. Doan이 GitHub로 보내는 네트워크 요청이 없다(앱 코드에 저장소 API 호출 없음).
7. `npm --prefix app test`, `npm --prefix app run typecheck`, `npm --prefix app run lint`가 통과한다.

## 비목표

- 별 개수 보이기, 별을 달았는지 확인하기, GitHub 로그인.
- 사용 통계나 원격 측정.
- 다른 홍보(뉴스레터, 공유 버튼, 리뷰 요청).
- 설정 화면의 토글.

# composer Markdown — spec

## 사용자

- **사람**: composer에서 메시지를 쓰고, 대화 스레드에서 자기가 보낸 버블을 다시 읽는다. 이번 기능의 사용자는 사람이다.
- **에이전트**: 받는 텍스트는 지금과 같다. 사람이 쓴 목록 기호(`- `, `1. `)가 그대로 간다(`turnPrompt`의 `parts[].userText`). 첫 줄 들여쓰기가 남는 것 외에 에이전트 쪽 변화는 없다.

## 문제 (관찰된 사실)

- composer 입력창(`ChipField`, contenteditable)은 모든 줄을 평문으로 그린다. `- ` 로 시작하는 줄을 여러 개 써도 목록 모양이 되지 않고, 다음 항목의 기호도 사람이 직접 친다.
- 보낸 버블(`UserMessage`, `ConversationThread.tsx:471`)은 `white-space: pre-wrap` 평문이다. 에이전트 답은 Markdown으로 렌더되므로(ARCHITECTURE §7, 에이전트 Markdown 문단) 같은 스레드에서 사람이 쓴 목록만 평문으로 남는다.
- 보내기 전에 `composeRequest`가 본문을 trim해서(`homeComposer.ts:39-43`) 첫 줄의 들여쓰기가 사라진다.

## 범위 근거

- 지원 범위는 순서 없는 목록(`ul`)과 순서 있는 목록(`ol`), 그리고 그 중첩(깊이)뿐이다. 사용자가 Claude 데스크톱 앱 composer 캡처로 확인했다(2026-11-19 대화): `- `는 •로 그려지고, 번호 목록은 `1.`이 그대로 보이며, 깊이마다 한 단계씩 들여쓰인다. `**굵게**`와 `---`는 평문으로 남는다. 다른 서식(굵게, 코드, 제목 등)은 넣지 않는다.

## 완료 조건

1. Home, Overview의 docked composer, 캔버스 대화 패널, 프로토타입 창 대화 패널의 입력창에서 줄이 `- `, `* `, `<숫자>. `로 시작하면 그 줄이 목록 항목으로 그려진다. `- `·`* `는 •로, 번호는 `<숫자>.`로 보인다. 항목 본문은 기호 너비만큼 내어쓰기된다(줄이 넘치면 둘째 줄이 본문 시작에 맞춰진다).
2. 목록은 중첩할 수 있다. 깊이마다 한 단계씩 들여쓰이고, 하위 번호 목록은 1부터 다시 센다. 텍스트에서 깊이는 줄 앞 공백으로 남는다(부모 항목 본문이 시작하는 칸만큼, CommonMark 규칙).
3. 입력창의 텍스트는 여전히 일반 텍스트다. 캐럿, 삭제, undo, 복사(평문, `- ` 기호와 들여쓰기 공백 포함), 붙여넣기는 목록 모양이 없을 때와 같다. 화면의 •는 그리기일 뿐 텍스트에 들어가지 않는다.
4. 목록 항목에서 Shift+Enter를 누르면 새 줄에 같은 깊이, 같은 종류의 기호가 붙는다(`- ` 다음은 `- `, `3. ` 다음은 `4. `). 내용이 빈 항목에서 Shift+Enter를 누르면 깊이가 0보다 크면 한 단계 내어쓰고, 0이면 기호를 지우고 목록을 끝낸다. Enter는 지금처럼 보낸다.
5. 캐럿이 목록 항목에 있고 제안(프리셋·스킬 목록 등)이 보이지 않을 때, Tab은 그 항목을 한 단계 들여쓰고 Shift+Tab은 한 단계 내어쓴다. 부모가 될 위 항목이 없어 들여쓸 수 없거나 깊이 0에서 Shift+Tab이면 지금처럼 포커스가 옮겨 간다. 목록 항목이 아닌 줄에서 Tab은 지금과 같다.
6. 한글 IME 조합 중에는 입력창을 다시 그리지 않는다. 조합 중 Shift+Enter는 조합을 끝낸 뒤 처리하며, 글자가 사라지거나 두 번 입력되지 않는다.
7. 보낸 버블은 목록 줄을 깊이까지 포함해 `ul`·`ol` 목록으로 그린다. 그 밖의 Markdown 기호(`**`, 백틱, `#` 등)는 지금처럼 평문으로 남는다. 앵커 칩(`SentChip`)과 스킬 단어 강조는 목록 항목 안에서도 같은 자리에 보인다.
8. 버블 텍스트는 지금처럼 드래그로 선택하고 ⌘C로 복사할 수 있다. 복사한 텍스트에는 목록 기호가 들어간다. 버블에는 Copy 버튼이 생기지 않는다(PRODUCT §5 'Text edit menu').
9. 보낼 때 본문 앞뒤의 빈 줄만 지우고, 첫 줄의 들여쓰기는 남긴다.
10. 대화 제목과 큐 행은 줄 앞의 목록 기호를 걷어 낸 평문으로 보인다.
11. Edit and resend와 복원된 초안은 보낸 원문(목록 기호 포함)을 그대로 입력창에 되돌린다.

## 비목표

- 목록 외의 서식(굵게, 기울임, 코드, 코드 펜스, 제목, 인용, 링크, 표)과 그 렌더.
- 목록 외의 WYSIWYG 편집, 서식 툴바, 서식 단축키, 새 편집기 의존성(tiptap 등).
- 체크리스트(`- [ ]`).
- `{{`·`}}` 금지 규칙 완화(PRODUCT §5 item 1, Send 규칙).
- 터미널 세션 대화의 기록 표시.

# 툴팁 E2E 회귀 후속 작업

- 기준: `decea85`, 통합 브랜치 `feat-comments-ui`, PR #8.
- 사용자 요청: 간헐 툴팁 실패 원인을 재현하고 수정한다. 최초 실패를 해결하면 PR #8에 포함해 main 병합하도록 후속 승인했다. 해결 입증 전에는 보류한다.
- 기존 실패 증거: `.scratch/comments-ui/evidence/final-first-attempt/`.

| 배치 | 소유 범위 | 모델·노력 | 검증 | 상태 |
| --- | --- | --- | --- | --- |
| Tooltip-fix | 툴팁 관련 E2E 및 입증된 원인에 필요한 최소 코드, POSTMORTEM | Astra medium: Electron 포인터·초기화 순서의 인과관계 판단 | 실제 Electron 재현 red→green, 원래 실패 전제 유지, 전체 E2E | `8e67a23`, `7dd7e0c`: 재진입 결함 수정·전체 검증 통과, 최초 원인은 미확정 |
| Tooltip-review | 보고서만, 수정 금지 | Astra medium: 원인 및 회귀 증거 독립 검토 | 원인·수정·회귀 검증, 남은 red 0 | 완료: red 0 / yellow 0, 최초 실패 해결 조건 미충족 |

워커는 같은 체크아웃에서 순차 실행한다. 지휘자는 제품 코드를 수정하지 않으며 워커 실행 중 추적 파일을 변경하지 않는다. 완료 시 문서 결론을 승격하고 이 임시 계획을 삭제한다. 확인된 수정은 기존 PR에 push한다. 최초 실패 해결을 입증해야 main 병합한다.

## 증거와 남은 조건

- `.scratch/comments-ui/tooltip-fix/handoff.md`, `review.md`: 원시 로그·소스 해시·수정 제거 검사를 독립 대조했다.
- 실제 Electron에서 Escape 이후 포인터 이탈 없는 재호버 실패를 재현하고 수정했다. 기존 정확한 툴팁 경로 검사를 유지했다.
- 전체 E2E 2회, 앱 1,112개 테스트, 타입 검사, Go test/vet 통과. 제품 코드는 변경하지 않았다.
- 최초 실패는 첫 hover에서 발생했으므로 Escape 이후 회귀와 같다고 단정할 수 없다. 창 표시·목록 갱신·일반 재시작 탐색에서는 재현하지 못했다.
- 독립 리뷰는 코드 결함 0건과 별개로 최초 실패 해결 조건을 미완료로 판정했다. 원래 전체 전반부 시나리오를 12회 순차 실행했고 전부 통과해 최초 실패는 재현하지 못했다. `.scratch/comments-ui/tooltip-fix/evidence/original-sequence-receipts.json`에 실행별 로그·종료 코드·소요 시간을 보존했다.

## 현재 인수 상태

확인된 사전조건 수정은 수용해 PR #8에 포함한다. 최초 timeout 해결 조건은 미완료이며 main 병합은 하지 않는다. 수정·리뷰 워커는 모두 정상 종료했고 새 자식 워크트리는 만들지 않았다. 원래 실패가 다시 발생하면 추가된 이벤트 진단으로 최초 hover 전후 순서를 대조해야 한다.

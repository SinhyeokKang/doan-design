# 구현 순서와 검증

각 단계는 앞 단계의 검증 결과를 이어받는다. 인스펙터 너비 작업과 뷰어 파일이 겹치므로 해당 PR의 통합 상태를 확인하고 최신 develop에서 시작한다. 앱 기준과 비교할 때 같은 캔버스에 재생 가능한 프레임, 중첩 프레임, 링크, 일반 입력, 잘못된 마크, 스크립트로 생긴 프레임을 넣는다.

| 순서 | 작업과 커밋 경계 | 검증 |
|---|---|---|
| 1 | 브라우저 PoC. 일반 Export 파일 하나로 새 창을 열어 격리된 프레임을 재생하고 연결된 단독 HTML을 저장한다. 실험물은 .scratch에 둔다. | 저장소 밖 임시 디렉터리에서 Chromium·WebKit으로 실제 파일을 연다. 팝업 허용·차단·재시도, 창 재사용, 원래 탭을 닫은 뒤의 동작, 다운로드한 파일의 오프라인 링크 이동을 기록한다. 브라우저별 차이나 미검증 항목은 구현 전에 보고한다. |
| 2 | 시안 확정. feature-review 후 design.md에 지정한 보드·서랍·재생·복구 상태를 그린다. | 설치된 CLI로 `doan check --repo . --json`과 `doan ls --repo . --json`을 실행한 뒤 앱에서 사용자가 시안을 확인한다. |
| 3 | TDD. 기존 마크·링크 fixture에 선택과 재생 대상, 서랍 그룹, 기록·모드, 내보내기 거절 사례를 연결하고 앱 결과와 Export 결과를 비교한다. 공개 스키마 변경은 없다. 테스트를 먼저 커밋한다. | `go test ./...`와 `npm --prefix app test`에서 의도한 새 단언이 실패하고 기존 앱 기준은 통과하는지 확인한다. |
| 4 | 일반 Export 조립. 원본 리소스는 한 번만 담고, 보드·재생기·개별 Export가 필요한 정적 프레임과 링크 정보를 전달한다. 이 단계에서 조립 변경을 커밋한다. | `go test ./...`로 CLI 출력 계약, 일반·단독 파일 구분, 50 MiB 경계, 링크 그룹, 중복·긴 ID, 이스케이프, 기존 단독 파일 호환을 확인한다. |
| 5 | Select와 보드의 재생 진입점. 인스펙터에서 선택을 분리하고 앱의 버블, 툴바, 서랍, 마크와 포커스 동작을 연결한다. 한 커밋 단위다. | `npm --prefix app test`와 실제 파일에서 접힌 상태·열린 상태·너비 부족 상태의 클릭, 중첩 선택, 거리 측정, 텍스트 드래그, 키보드·포인터, 서랍의 Fit과 Play 차이를 확인한다. |
| 6 | 브라우저 재생창. 창 열기·재사용과 분리된 프레임 렌더링, Fit·Responsive, 링크·서랍·기록·Reload, 실패·재시도와 포커스를 구현해 커밋한다. | `npm --prefix app test`와 같은 fixture의 앱·브라우저 비교로 뷰포트 치수, 모드 전환 후 입력 보존, 프레임 변경 후 초기화, 자기 링크 재시작, 링크 취소, 팝업 차단 후 보드 상태 보존을 확인한다. |
| 7 | 현재 프로토타입 내보내기. 클릭 시점의 프레임·링크 그룹으로 독립 파일을 내려받게 한다. 성공·거절·진행 안내와 함께 커밋한다. | `go test ./...`와 `npm --prefix app test`를 실행한다. Chromium·WebKit에서 실제 받은 파일을 빈 폴더로 옮겨 원래 뷰어를 닫고 열어 시작 프레임·링크·브라우저 기록을 검증한다. 다른 그룹, 단독 프레임, 동적으로 생긴 프레임의 거절도 확인한다. |
| 8 | 통합 검증. 두 브라우저의 일반 Export와 앱이 만드는 단독 Export에서 같은 시나리오를 재생하고 증거를 남긴다. | `node .agents/skills/verify/scripts/verify.mjs`와 짧은 실제 앱·파일 검증을 수행한다. 지원 브라우저 실측과 자동화 엔진 결과를 구별해 기록한다. 가이드·CLI 출력·검사 규칙이 바뀌면 저장소 규칙에 따라 agent-eval을 수행한다. |
| 9 | 구현된 동작을 영문 PRODUCT·ARCHITECTURE 및 해당 DESIGN 절에 반영하고 이 기능 디렉터리를 삭제한다. 각 기준 문서는 따로 커밋한다. | 공개 문서·가이드에서 기존의 인스펙터 의존 선택과 재생 제한 설명을 찾아 구현과 대조하고, 문서 링크 및 기능 디렉터리 삭제를 확인한다. |

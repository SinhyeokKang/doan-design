# Export HTML에서 프레임 선택과 프로토타입 재생

## 사용자와 문제

디자이너나 개발자가 일반 캔버스 HTML 한 파일을 전달하면, 받는 사람은 Doan이나 저장소 없이 브라우저로 디자인을 살펴본다. 현재 일반 Export에서는 인스펙터를 열어야 프레임을 선택할 수 있다. 프레임 서랍에서 행을 고르면 해당 프레임에 맞춰 보드를 이동한다. 재생하려면 보낸 사람이 프로토타입을 따로 내보내야 한다. 그 파일은 브라우저 창을 채워 재생하며 앱 재생기의 조작부가 없다. [현재 동작](../../PRODUCT.md#5-mvp)

## 완료 조건

1. 일반 Export를 오프라인으로 열고 인스펙터를 접은 채 프레임을 선택한다. 일반 클릭, 중첩 프레임 진입, 직접 선택, Esc, 호버, 텍스트 선택과 복사, 거리 측정, Option 클릭이 앱과 같다. 인스펙터를 열거나 접어도 선택과 보드 탐색을 이어간다.
2. 재생 가능한 프레임을 선택하면 크기 버블과 툴바 양쪽에서 재생할 수 있다. 내부 요소를 선택했을 때는 툴바가 가장 가까운 재생 가능한 상위 프레임을 찾는다. 툴바의 대상 판정과 재생 서랍, 프레임 서랍의 프로토타입 마크와 키보드 조작은 앱을 따른다.
3. Play를 누르면 별도 브라우저 창에서 선택한 프레임이 재생된다. 브라우저 설정으로 새 탭에 열려도 원래 보드의 선택·확대율·스크롤은 유지된다. 재생 중인 같은 프레임을 다시 열면 입력 상태를 유지한다.
4. 재생기에는 앱의 이전·다음, 다시 시작, 프레임 서랍, Fit·Responsive, Export prototype이 있다. 링크 이동, 현재 프레임 표시, 포커스, 로딩·실패·복구 동작도 해당 앱 기능을 따른다. 대화 패널과 에이전트 관련 조작만 제외한다.
5. 재생기에서 현재 프레임을 별도 HTML로 내려받는다. 그 파일을 원래 뷰어와 저장소가 없는 환경에서 열면 내보낸 프레임부터 시작해 연결된 프레임을 재생할 수 있다. 기존 앱·CLI의 개별 프로토타입 내보내기와 같은 결과를 기준으로 삼는다.
6. Chromium과 Safari 계열에서 실제 로컬 HTML로 위 흐름을 확인한다. 브라우저가 새 창을 막아도 보드는 남고 사용자가 차단을 해제한 뒤 Play로 재시도할 수 있다.

## 범위

대상은 일반 Export의 Select 및 재생 진입점과 거기서 여는 재생기다. 대화·에이전트 연결, 메시지용 Picker·Capture·칩은 제외한다. 인스펙터 너비는 별도 작업에서 정하며 그 결과와 함께 검증한다. 이미 배포한 HTML은 기존 동작을 유지하고 새로 내보낸 파일부터 적용한다. 호스팅, 앱 설치, 새 CLI 플래그나 캔버스 마크를 요구하지 않는다.

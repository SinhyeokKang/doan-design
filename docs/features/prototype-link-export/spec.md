# prototype-link-export — spec

상위 feature [prototype-frame-links](../prototype-frame-links/spec.md)의 하위 3이다. 프로토타입 내보내기가 연결된 프레임 묶음 전체를 한 파일에 담고, 내보낸 파일이 브라우저에서 연결을 따라 프레임을 바꾼다. 하위 1(`prototype-link-convention`)의 묶음 계산과 하위 2(`prototype-link-play`)의 연결 동작 위에 선다. 상위 문서의 공통 결정을 따르고, 상위 문서는 고치지 않는다.

## 사용자

- **사람**:
  - 프로토타입 창에서 Export로 흐름 전체를 한 파일로 저장해 보낸다.
  - 받은 사람은 브라우저에서 연결을 눌러 화면을 오가고, 브라우저 Back과 Forward로 돌아간다.
- **에이전트**: `doan export --frame <id> --prototype`으로 같은 파일을 만든다. 명령은 바뀌지 않는다.

## 문제

- 내보낸 프로토타입 파일은 프레임 하나만 재생한다. `isolate.js`가 `const FRAME = <json>;` 하나로 그 프레임만 남기고, 다른 요소를 영구히 숨긴다(`cli/internal/export/viewer/isolate.js:61-84`). 그래서 하위 2가 병합된 뒤에는 연결이 창에서는 동작하고 파일에서는 아무 일도 하지 않는다.
- `isolate.js`는 `#` hash 링크 말고 모든 링크 클릭을 막는다(`:44-57`).

## 완료 조건

1. 창의 Export와 `doan export --frame <id> --prototype`이 같은 파일을 만든다.
   - 그 프레임이 속한 묶음(하위 1 `LinkGroups`)의 모든 프레임을 담고, `<id>` 프레임에서 시작한다.
   - 연결 없는 프레임이면 지금처럼 그 프레임 하나다.
   - 명령의 인자, 오류 코드, 메시지는 바뀌지 않는다.
2. 파일 이름은 지금과 같다(`<canvas file stem>-<frame id>.html`, 시작 프레임).
3. 내보낸 파일에서 연결을 누르면 대상 프레임이 새로 시작한다. 판단 규칙은 하위 2와 같다.
   - 클릭을 만드는 입력이면 이동한다.
   - 캔버스 스크립트가 `preventDefault()`를 부르면 이동하지 않는다.
   - 눌린 요소에서 가장 가까운 연결 하나만 따른다.
   - 자기 프레임으로 가는 연결은 처음부터 다시 시작한다.
4. 이동은 바깥 페이지의 hash에 기록된다. 브라우저 Back과 Forward가 프레임을 따라가고, 돌아간 프레임도 새로 시작한다.
   - 파일을 hash와 함께 열면 그 프레임에서 시작한다. 단, 묶음에 있는 프레임일 때만이고, 아니면 시작 프레임이다.
   - 파일에 헤더나 버튼은 더하지 않는다.
5. 묶음 밖으로 가는 연결이나 재생할 수 없는 대상으로 가는 연결은 파일에서 아무 일도 하지 않는다. 파일에는 토스트가 없다.
6. 브라우저 탭 제목은 지금처럼 정해지고, 프레임이 바뀌면 그 프레임의 제목이나 id를 따른다. 제목 규칙은 지금 `{{NAME}}`을 정하는 규칙과 같다.
7. 로딩 실패 문구("This prototype's frame didn't load…")와 10초 시한은 이동한 프레임마다 다시 적용된다.
8. 파일 크기 한도(50 MiB)와 오프라인 동작은 지금과 같다. 캔버스는 한 번만 담는다.
9. 기존 내보내기(연결 없는 프레임, 캔버스 export)의 출력은 연결이 없는 캔버스에서 바뀌지 않는다. 고정 테스트(`TestExportOutputIsPinned`, `TestAssembleOutputIsPinned`)는 그대로 통과한다. 프로토타입 페이지의 스크립트가 바뀌어 바이트가 바뀌는 것은 허용하고, 그 고정 테스트는 갱신한다.
10. `/agent-eval` X2가 그대로 통과한다. X2는 내보낸 파일을 같은 CLI가 다시 만든 기준 파일과 비교한다.

## 하지 않는 것

- 파일 안의 프레임 목록, 헤더, Back 버튼(상위 결정 7).
- 묶음 여럿을 한 파일에 담는 것. 끊긴 묶음은 따로 내보낸다.
- 캔버스 export viewer(`viewer/shell.js`)에서의 연결.
- 프로토타입 창 쪽 변경. 하위 2가 한다.

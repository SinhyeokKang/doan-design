# 대형 캔버스 렌더링 안정화 작업

- [ ] 1. PoC 시작 시 사용자에게 원본 캔버스·Export HTML을 받고 재현 동작과 환경을 확인한다. 검증: 자료·의존 파일의 경로와 지문, Export 생성 버전, 앱 커밋·Electron/브라우저 버전·로드 상태를 기록하고 같은 시점의 자료인지 확인한다. 아직 자료 미제공이다.
- [ ] 2. 격리 앱과 Export HTML 비교 PoC로 원인을 좁히고 완료 기준·필요한 구조 변경을 사용자에게 확인한다. 검증: `DOAN_CLI=<abs path to doan> npm --prefix app run dev -- -- --user-data-dir=<tmp>`로 전후 비교의 기준 화면과 확대·이동 구간을 기록한다. AGENTS.md의 HOME·SHELL·에이전트 설정 격리를 적용한다. 브라우저 비교용 명령은 미정이며 사용자 확인이 필요하다. 알려진 앱/Export 차이는 별도 분류한다. 재현 실패·원인 미확정이면 관측과 추가 자료를 보고하고 구현을 중단한다.
- [ ] 3. 원인이 확인된 경계에 회귀 증거를 고정한 뒤 수정한다. 검증: 계산·상태 문제는 `npm --prefix app test`의 단위 red, GPU·합성 문제는 작업 2의 동일 probe에서 변경 전 실패 화면·측정을 먼저 확보한다. 기존 좌표·높이·재로드 단위 검사는 별도로 통과시킨다. **원인별 구현 커밋 경계**.
- [ ] 4. 같은 자료·환경·동작으로 `/runtime-test`를 실행하고 `/code-review`·`/postmortem`을 수행한다. 검증: 작업 2와 같은 격리 앱에서 전후 화면·측정 비교, `node .agents/skills/verify/scripts/verify.mjs`. 높이·가시 영역·스케줄링을 건드리면 화면 밖 재로드·늦은 폰트·이전 viewport 측정도 확인한다. 합의한 개선 기준을 충족해야 완료하며, 남은 현상은 사용자에게 확인받는다. 해결하지 못한 조건은 통과로 보고하지 않는다.
- [ ] 5. PRODUCT·ARCHITECTURE에 실제 변경된 현재 규칙을 영문 승격하고 관련 BACKLOG 미확인 항목을 증거에 맞춰 갱신한 뒤 이 디렉터리를 삭제한다. 검증: 재현·회귀·잔여 제한의 증거를 대조한다. **문서별 커밋 경계**.

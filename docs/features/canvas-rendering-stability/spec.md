# 대형 캔버스 렌더링 안정화

## 순서와 사용자

다섯 기능 중 3번이다. 앞은 `frame-first-selection`, 뒤는 `frame-prototype`이다. 큰 캔버스를 보고 확대·축소·이동하는 사람이 대상이다.

## 문제와 현재 증거

사용자가 큰 캔버스의 그래픽 깨짐을 보고했다. 원본 캔버스와 Export HTML을 PoC 진행 시점에 제공하기로 했다. 아직 해당 자료를 받거나 현상을 재현하지 않았다. 잘림·빈 영역·깜빡임 중 무엇인지, 발생 동작, GPU·합성·레이아웃 중 어느 경로가 원인인지 확정하지 않는다.

## 완료 조건

1. 제공받은 원본과 Export HTML에 대해 앱·브라우저에서 같은 크기·배율·동작으로 재현 여부를 기록한다. 한쪽에서 재현되지 않는 결과도 보존한다.
2. 화면 크기·디스플레이 배율·캔버스 크기·프레임 수·확대율·재현 순서와 전후 화면 증거가 있다.
3. 재현 뒤 정한 회귀 조건에서 깨짐이 해결되거나 남는 범위가 수치·화면으로 구별된다. 허용할 잔여 현상과 성능 기준은 PoC 결과를 보고 사용자에게 확인한다.
4. 일반 크기 캔버스의 선택 위치·프레임 점프·Capture area·재로드·스크롤·모션이 유지된다. 다른 현상을 숨기기 위해 상호작용을 끄지 않는다.

## 비목표

원인 확인 전 가상화·타일 렌더링·GPU 옵션을 확정하지 않는다. 캔버스 포맷 개편, 근거 없는 FPS 목표, 전체 e2e 도입은 하지 않는다. Export HTML은 비교 자료이며 export 코드 수정 범위는 원인을 확인한 뒤 결정한다.

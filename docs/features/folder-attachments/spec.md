# 폴더 첨부

## 순서와 상태

다섯 기능 중 1번이다. 다음은 `frame-first-selection`이다. 기능 문서 적재 단계이며 구현하지 않았다.

## 사용자와 문제

사람은 대화에서 참고할 폴더를 지정하고, 에이전트는 전달받은 경로를 자신의 도구로 읽는다. 현재 파일만 첨부할 수 있고 폴더는 거부한다(PRODUCT §5 item 1 Attachments).

## 확정 범위

- Home·Overview·캔버스 대화의 모든 입력창에서 폴더를 첨부한다.
- Attach는 macOS 선택창에서 파일과 폴더를 선택한다. 경로 입력은 선택창의 ⌘⇧G를 사용한다. 별도 경로 입력 UI는 만들지 않는다.
- 폴더 드래그앤드롭과 Finder에서 복사한 폴더 붙여넣기도 같은 첨부 칩을 만든다.
- 프로젝트 밖 폴더도 허용한다. 파일·이미지·폴더 합계로 요청당 10개 제한을 유지한다.
- 폴더 내용을 복사하거나 묶어서 보내지 않고 경로를 전달한다. 첨부는 에이전트의 접근 권한을 자동으로 확장하지 않는다.

## 완료 조건

1. 세 입력창에서 Attach·드롭·붙여넣기로 내부·외부 폴더를 추가하고 제거할 수 있다.
2. 파일과 폴더가 섞인 요청의 한도를 동일하게 검사하며, 거부 시 기존 초안을 유지한다.
3. 전송 직전 사라지거나 다른 종류로 바뀐 폴더는 기존 첨부 수락 절차에서 거부한다.
4. 지원하는 다섯 제공자에게 폴더 경로가 전달된다. 실제 읽기 성공 여부와 권한 거부는 별도로 검증한다.
5. 큐·Send now·초안 복원·대화 재시작에서도 폴더가 파일이나 이미지로 바뀌지 않는다.

## 비목표

폴더 재귀 복사, 압축, 업로드, 자동 내용 삽입, 프로젝트 등록, 권한 모드 변경은 하지 않는다.

### Documented deviations from the draft

- **Streaming caret height.** The drafts draw the caret 24 high with a −6 px bottom margin in every type size; the app draws it one line tall (20 in the canvas panel's 14/20 text), because the drafts' caret makes a 14/20 line 23 high.
- **Conversation menu width.** 360 px is the menu's component constant; the draft's own rule asks for 360 but the shared `.doan-menu` `max-width` caps its render at 320.
- The Overview header, New conversation button and worktree menu share the [inherited header type](canvas.md#worktree-header-type).
- **Current worktree check.** The worktree menu marks the current row with a check. Opening recovery actions moves the check and `aria-current` to the worktree being repaired.
- **Worktree status.** A problem worktree carries Home’s toned status chip. Its status stays visible when that row is checked for repair (see Home, “Status chips in menus”).
- **Running canvas row.** `overview-thread` draws a canvas row as Working while the project conversation runs. A project conversation is never bound to a canvas: a canvas it makes gets a row only when a handoff starts that canvas's own conversation after the turn, so the draft's state cannot occur.
- **Promotion frames.** `overview-promoted` and `overview-conversation-list.html` `promoted` draw a shown project conversation moving to a canvas, which no longer happens; nothing is measured from them.
- **Cursor.** Plain buttons (activity head, rows) take the app-wide `button { cursor: pointer }`; the draft's plain buttons keep the default cursor.
- **Provider text.** Model and effort labels, activity summaries ("Using a tool") and permission option labels ("Allow", "Allow with suggested permissions") come from the provider; the draft's samples are "Opus 5.5", "High", "Editing …", "Allow once".
- **List read failure alignment.** The draft's `.rp-error` keeps `justify-content: space-between`; the app's has none. Its text span takes the free space (`flex: 1`), so the icon, text and Retry measure at the same positions.
- **Thumbnails.** The app shows the captured canvas (`object-fit: cover`, top) in a 48 × 48 px cell with a 12 px gap. The draft draws a 72 × 48 px mock fill with an 8 px gap.
- **Empty-title Delete name.** A conversation with no title names its row's Delete "Delete this conversation" (the shared `deleteItemLabel`, as the title menu); `canvas-concurrent-conversations.html` `overview-rows` draws "Delete “Conversation”".
- **Unreadable canvas row.** A conversation whose canvas file cannot be read keeps an openable row with the metadata caption: it opens the canvas page, which shows the read error. The `overview-rows` problem tile draws all three problem rows unavailable with the danger caption; the gone and duplicate-ID rows match it.
- **Narrow placeholder.** The capsule's placeholder stays on one line, so the empty capsule is as tall as one with a typed character; at narrow widths it ends in an ellipsis. The full text stays the field's `aria-placeholder`. A next-message suggestion follows the same rule, and the box's empty placeholder (an attachments-only draft) is one ellipsized line too, so the field stays one line tall (24 px) with no scroll when a suggestion comes or goes (measured in the real app).

### Not verified

- Right-panel rows were measured in Working, Needs your answer and usage-limit states from a replaced list handler, not from real agent turns (see 'Running canvas row').
- The `no-current` tiles "Just started, not listed yet" and "Next list read" (a real start needs an agent; the current row's rules are unit-tested); keyboard focus was set with `focus({ focusVisible: true })`, not a real Tab key; Retry's hover.
- Docked composer with preset chips and no text and Sending; the bubble's preset line; an expired permission; the “Moved to” marker an earlier Doan's promotion left (canvas conversations, shown on the canvas page); Jump to latest; the action rows of a failed or sign-in notice that is not the latest end (only the latest end offers actions).
- Keyboard focus rings on the Overview’s worktree switch and New conversation button.

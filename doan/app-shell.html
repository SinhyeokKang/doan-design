doan app shell — V1 (app-ui draft)

Single dark theme · orange accent · one system sans. Tone from Sorcerer, layout from Figma-style layers + design panel (V1). All app UI copy is English, and folders are called Project on screen (code keeps the name folder). app-ui implements Main and the state frames. The right panel has no tabs, only the “Canvas” header with the information that exists today; #6 and #7 decide their own panel layout. Dashed yellow marks and the “After #6 · #7” frame are not in code yet. The white screen on the board (“Acme Sign in”) is the canvas the human reviews, so it does not follow the app colors.

References: github.com/gbrasil720/sorcerer (MIT, README screenshots · badge colors F0773A · ECEBE4 · 8F8E87) · Figma · Storybook · Claude Design — the design-tool layout is from memory and was not rechecked against screens.

Closing the window — macOS convention
Closing the window (red button or ⌘W) hides it and keeps doan running in the Dock (watchers and the local server stay up). Click the Dock icon or press ⌘O to show the same window again. Quit with ⌘Q. ⌘W never closes a project; a project closes only from its row’s Close.

doan / Buzz Restyle / 01

A quiet sidebar. One white canvas surface.

Search (⌘K) stays at the top of the sidebar. Add Projects, Projects and Settings form a capsule button group in the header; Projects is selected in this static study. Search is a button that opens the existing Quick Open modal, not an inline input. The sidebar lists projects. Expand a project to see canvases from its selected worktree. The branch badge is read-only. Open the trailing project action to choose a worktree in the project dropdown. The current project cannot collapse. Canvas frames no longer appear in this sidebar. Project names use the same text size and alignment as canvas rows, with a heavier weight; canvas rows sit directly below them. Groups are separated by space. The header also contains Back and Forward arrows. Each is enabled only when its history destination exists; Home samples show an empty history. C still compares sidebar width. Home content remains provisional. Shell and sidebar design approved on 2026-10-27. The 260px sidebar is the implementation baseline; the 240px and Home studies remain comparison history. These are static studies, not an implemented app.

IA revision, not just a restyle: project rows, canvas leaves and worktree menus are proposed here. Project icons show letter fallbacks; repository-host images are a separate possible integration. Canvas controls, Canvas info and comments remain context samples. The shell and LNB share a translucent, blurred backdrop; only the main body is opaque white. Selection uses neutral shading, never violet. Wallpaper and CSS blur simulate the material; real macOS vibrancy is not implemented. Native traffic lights are neutral position mocks. Example canvas content is fictional.

Copied 2026-10-29 from the approved draft's `.doan/assets/provider-logos/` for the app's Agent step; the notes below are that directory's. Retrieved 2026-10-28 from official provider sites or repositories. These local assets were draft references; inclusion is not a claim of trademark ownership or endorsement. App packaging and brand-use requirements remain implementation work.

- `claude.png`: https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png?w=64&h=64 — icon linked by claude.com.
- `codex.png`: https://github.com/openai.png?size=64 — official OpenAI organization avatar, used as the OpenAI provider mark for Codex, not a distinct Codex product icon.
- `cursor.svg`: https://cursor.com/marketing-static/favicon-light.svg
- `antigravity.svg`: https://antigravity.google/favicon.svg
- `copilot.svg`: https://raw.githubusercontent.com/primer/octicons/main/icons/copilot-24.svg — GitHub Primer Octicons, MIT: https://github.com/primer/octicons/blob/main/LICENSE

Processed 2026-10-28 so every mark is a bare glyph on a transparent background, cropped to its own bounds, for a uniform 24px glyph box in a 32px slot: `cursor.svg` keeps only the cube path (the app-tile background and outline are removed, viewBox cropped to the cube); `antigravity.svg` drops the white favicon circle and its dark-mode style (viewBox cropped to the arch); `codex.png` converts the avatar's white square to transparency (alpha from darkness) and crops to the knot; `claude.png` is cropped to its bounds. The originals are the URLs above.

SVG assets are stored without scripts or external resource references. Provider names remain visible beside decorative marks.

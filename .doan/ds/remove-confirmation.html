remove-confirmation

The compact, centred dialog that asks before removing a project whose Home conversation is still running (App.tsx, copy from homeConversations.ts). Removing from the sidebar opens it on any screen; Cancel has focus and Escape cancels. Drawn in place.

Open: its actions are sm buttons, where the dialog rule in docs/DESIGN.md puts dialog actions at the default size. Whether this dialog follows that rule or is an exception is undecided.

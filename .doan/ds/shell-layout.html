shell-layout

The frame Home, the workspace, Add Projects and Settings share: a 56px header (--size-chrome) with the history buttons and the centred page tabs (see mode-tabs), a 220px sidebar, and the screen's white body panel, all on the shell, which shows the native sidebar material (--bg-app under reduced transparency, and on this canvas). Its rules live in styles.css and are restated here, with hover and focus as .is-hover and .is-focus. Project names, branches and canvas names are sample data. The id app-shell belongs to an older draft, so this canvas is shell-layout.

Open: sidebar rows use an 8px corner and the shell sizes several parts with literals (220px, 36px, 10px type) that no token names; whether they become tokens is undecided. The current row and hover use neutral backdrop roles, while tokens.css still describes violet for them.

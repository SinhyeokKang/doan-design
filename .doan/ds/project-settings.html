project-settings

ProjectSettingsDialog: the standard-width dialog opened from a sidebar project's menu on any screen. Each value saves at once, so Done is its only action; Done and Escape close it, refused while a pick, confirmation or write runs. The Add to Serve confirmation it opens is the add-to-serve canvas. Its layout rules live in styles.css and are restated here; the dialogs are drawn in place.

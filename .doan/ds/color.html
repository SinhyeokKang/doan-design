color

Three layers in tokens.css: the palette holds the only literal colours, roles say what a value is for, and legacy names alias roles for older drafts. Renderer code reads roles only, so the palette frames show the source of each role, not values to use directly. The legacy layer is not drawn: no renderer code reads it.

Open: the comment on the violet roles in tokens.css names the current sidebar row and its hover, but styles.css draws both with neutral backdrop roles (.shell-side .row overrides .side .row). Whether the sidebar violet roles stay, go or come back is undecided.

inline-error

An inline error or warning is one body-sm line led by the 16px alert icon, in --text-danger or --text-warning, so colour is not the only signal. Two class families draw it: .ob-msg (with .fp-error and .pj-msg; Project Setup, the first prompt, Home) and .settings-msg (Settings pages, Project Settings), which adds the body-sm tracking. Both are restated here from styles.css.

SettingsDialog: the compact, centred confirmation before a write, opened over the Project Settings page when a path is about to be shared with canvases, as an alertdialog. The title and body name the path as a code chip, repo-relative inside the worktree. Focus starts on Cancel, so automatic focus never lands on the action that writes; Escape answers Cancel. The inline-code rule is restated from styles.css; the dialog is drawn in place.

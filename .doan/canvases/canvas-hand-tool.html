canvas-hand-tool · draft · 6 frames

The Hand tool, Space drag, and one key hint for dark materials.

Scope: docs/features/canvas-hand-tool/ (spec, design). The canvas page is on main; this draft is a new file drawn as a user-approved exception (feature review), and buzz-canvas.html stays untouched. /design-sync compares every frame below.

  • New, not in code: the Hand tool and its pressed state, tooltips that name a key, the shared key variant doan-kbd[data-ui-variant="on-prominent"] with its sm size, the drag layer (outlined here only to show where it sits; the app draws nothing), and the grab and grabbing cursors.
  • Copied as shipped (cce75bb6): the tools row, pressed fill, canvas status, agent notice and picking hint from app/src/renderer/styles.css, CanvasTools.tsx, CanvasAgent.tsx and App.tsx; tokens and primitives linked from app/src/renderer/.
  • Cursors are drawn as illustrations with a label, because a static draft cannot show the OS cursor. They use lucide hand and hand-grab (lucide-react 1.61.0, checked in app/node_modules); the app sets CSS grab / grabbing.
  • References: V for Select, H for Hand, Space to pan while held, and the grab cursors follow Figma's canvas conventions (recalled from memory, not checked in this session).

02

Tools row · Hand New, not in code

Hand is pressed after H or a click on it, and stays pressed across canvases and relaunches until Select, V or Esc; Select is the default on first launch. Pressing it again keeps it pressed. On a canvas opened in Hand, this pressed button and the grab cursor are what tell the person a click will not select.

03

Key hint on a dark material New variant, not in code

One shared variant, doan-kbd[data-ui-variant="on-prominent"]: transparent, the parent's ink, a 1px ring of that ink at 45 %. The default size is the picking hint's Esc, unchanged from today (28 high). data-ui-size="sm" is the in-button key's size (caption, 0 / 6, 16 high), so a tooltip stays 24 high. The picking hint's screen-only .doan-picking-esc rule goes away with no change in computed values.

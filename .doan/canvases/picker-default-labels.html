03

Docked tray · width stepsNot in code

Every control in the tray is 2px apart (Attach, Pick, model, effort, permission) and the context ring 4px after the last picker (shipped: 4px, and 8px before the ring). The steps move earlier so the model name stays whole: below a 432 content width Permission shows its icon only (shipped: 384), below 384 Effort does too (shipped: 288), and the model label ellipsizes last, below 320. The boundaries come from the widest labels, measured in this draft: “GPT-5.6-Terra”, “Extra high” with the Fast icon and “Ask first” need 432 (Attach 24, Pick 24, model 130, effort 127, permission 99, ring 16, gaps 12); with Permission as an icon (48) 381; with both as icons (effort 66) 320. A hidden label stays in the tooltip and the aria-label.

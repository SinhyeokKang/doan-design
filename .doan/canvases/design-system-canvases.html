Design system and Canvases in the sidebar

Feature design-system-canvases (docs/features/design-system-canvases/design.md, sidebar and Q6–Q8). Under an expanded project the sidebar shows two groups in this order: Design system (canvases under .doan/ds/) and Canvases (under .doan/canvases/). Each group head opens and closes its list and carries a count badge; an empty group still shows. Only the sidebar changes in this feature; the Overview's .doan/ds section belongs to buzz-project.

New, not in code: the group heads (chevron, label, count badge), the third tree level and its indent, the empty line “No design system yet”, the SwatchBook icon on design-system rows and PanelsTopLeft on canvas rows (replacing Palette; Quick Open takes the same two icons, not drawn here). Copied from shipped code (app/src/renderer/styles.css, ShellSidebar.tsx, DESIGN.md ‘App shell’): the search, Projects heading, project row, canvas row, status slots, read-error line, locked ink and the sidebar material. Static .is-hover/.is-focus classes stand in for :hover/:focus-visible.

/design-sync compares every frame. References: icon paths from lucide-react 1.61.0 in app/node_modules (checked); the sidebar material stage is the same approximation as buzz-shell.html, not a measurement.

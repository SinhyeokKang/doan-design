quick-open-conversations · draft round 2 · 7 frames

Quick Open, with conversations.

Scope: conversations in Quick Open (docs/features/quick-open-conversations/spec.md and design.md, ‘초안 요청’). New here, and not in code: the Conversations tab (fourth, after All, Canvases and Frames), the field’s name and placeholder “Search canvases, frames and conversations”, conversation rows (title; “<canvas name> · <time>” or “Project conversation · <time>”, no time when the history could not be read), conversations mixed into All, the empty-query Conversations lists, the new empty texts, conversation lists counted in the reading row, and the toasts when a chosen conversation can no longer be opened. All seven frames are new. /design-sync compares results-conversations, no-match and open-failed.

Decided by the user (round 2): 1. The Conversations tab and every conversation row use lucide MessagesSquare; MessageCircle already marks a finished, unread conversation (sidebar slot, panel badge). 2. One open-failed toast per cause, in copy shapes the app already has (frame 07), the title through the shipped quoted(). 3. After an open failure, focus returns to where Quick Open was opened, as Escape does. 4. A row’s accessible name spells the time out like the menu’s ShortTime.label (“12 minutes ago”, “Just now”), while the row shows the short form (“12m”, “now”). 5. Canvases and frames keep the shipped tie order; only conversations go after them at equal score and proximity.

Copied from shipped code, not redesigned: the Quick Open dialog, field, tabs, groups, rows, match underline, empty text and reading row (app/src/renderer/QuickOpenDialog.tsx, quickOpen.ts, styles.css .qo-*, .group-tabs, .shell-modes, .shell-thumbnail, ds/surfaces.css search presentation; docs/DESIGN.md ‘Quick Open’), the toast (Toast.tsx: .toast, .doan-toast, .msg.selectable), the toast sentences (quoted() in conversationDelete.ts, replyChipRefusal in App.tsx), the time text (shortAgo in overviewConversation.ts, used by the Conversation menu) and the canvas name (canvasLabel, the file stem). The shipped .doan/canvases/doan-search.html is the earlier draft of this dialog and is not edited; where it and the code differ (its Palette canvas icon, its reading frame), this draft follows the code. Canvas-only: the page, captions, the dialog drawn open in place on a 688×599 stage instead of the top layer of a 1238×780 window, the 429px list height that stands for min(55dvh, 576px) there, and the toast stages. Project, canvas, conversation names and times are illustrative and one fixture across all frames (a conversation has the same place and time wherever it appears); group hues are projectHue() of the names (acme-web amber, brand-kit sky).

References: lucide-react 1.61.0 as installed in app/node_modules (Search, Layers, PanelsTopLeft, Hash, MessagesSquare), checked; shortAgo, canvasLabel, quoted() and replyChipRefusal read from the source, checked. Presets read: shape, clarify, critique.

01

Workspace · All · results for “checkout”Not in code

acme-web · main is loaded and the person typed “checkout” on All. Conversation titles join canvases and frames under the same ranking: match score first, then proximity (this root, other worktrees of this repository, other repositories). Canvases and frames keep the shipped tie order, the index order (each canvas followed by its frames, canvases in list order): the frame “Checkout summary” of billing comes before the canvas checkout. Conversations come after canvases and frames of equal score and proximity. Rows 1–3 are prefix matches, rows 4–5 word-start matches; groups keep the order of their best row, so acme-web · main leads, then its feat-billing worktree, then brand-kit. The list is taller than its fixed height and scrolls as before.

02

Workspace · Conversations · results for “onboarding”Not in code

The Conversations tab with a query: conversation titles only, ranked as on All. Each row: the conversation icon (MessagesSquare), the title (matched letters underlined), and a second line naming where it lives, the canvas name (its file stem, as the sidebar names it) or “Project conversation”, then “ · ” and the last activity in the Conversation menu’s short form (shortAgo: now, 12m, 2h, 1d, then “Oct 28”, with the year when it is not this year). Row 3’s history could not be read, so it carries no time. Row 2’s long title and row 4’s long canvas name with its time end in an ellipsis on one line; the full text is in title. Archived conversations look the same as current ones. Compared by /design-sync.

03

Workspace · Conversations · empty queryNot in code

Conversations tab with no query in a workspace: that root’s conversations only, most recent activity first, at most 50. A conversation whose history could not be read has no time and goes last. All and Canvases with no query still list canvases only, as now.

04

Home · Conversations · empty queryNot in code

Conversations tab with no query on Home: every saved project’s conversations, most recent first, at most 50 in all. Groups are ordered by each root’s most recent conversation (brand-kit now, acme-web · main 12m, its feat-billing worktree 3h, below the fold), and rows inside a group stay most recent first, so brand-kit’s 5h and Dec 30, 2025 rows sit above acme-web’s 12m one.

05

Empty resultsNot in code

The four empty texts of the spec, one tile each (the “other results” form on two tabs). Body-sm subtle ink centred in the list and a polite status, as the shipped empty text. Compared by /design-sync.

06

Conversation list still loadingNot in code

A project whose conversation list is still being read joins the shipped reading row (“Still reading <n> projects…”). It is counted on Conversations and on All with a query (an empty All shows canvases only), once per project even when its folder is also being read. A project whose conversation list failed is not counted and shows nothing here; recovery is its Overview’s Retry.

07

Couldn’t open the conversationNot in code

One toast per cause, at the moment of choosing. The shipped toast (bottom right, 16px from the window’s edges, no action, a polite status, a selectable message) with copy built from shapes already in the app: the title quoted as the delete toasts quote it, and the reply-chip refusal’s sentences. <project> is the sidebar’s project name. Quick Open has closed, the screen stays where it was, nothing is added to Back/Forward, and focus returns to where Quick Open was opened, as Escape does. Compared by /design-sync.

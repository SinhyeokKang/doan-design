A little ground above the conversation

Doany + Puri · exploratory motion PoC · not in code. The existing docked input’s top border is the floor. Short grounded hops, rest, blink, look down while typing and look up toward the thread.

Eight frames: two component studies, two Project Overviews, two canvas pages and two narrow-panel stress cases. UI copied from current renderer code at c2bec43a; illustration content is dummy data. No feature specification or implementation contract.

Checked sources: DockedComposer.tsx, ProjectOverview.tsx, App.tsx, styles.css, tokens.css and shared ds CSS. Shell markup adapted from readme-features; buddy artwork and WebGL rig from buddies/motion-preview.js. Presets: shape, critique, animate. Native vibrancy is approximated by the shell background. Renderer CSS comparison: 100 elements × 14 properties, no differences before buddy palette mapping. Markup reviewed against current components; this is not a live Electron equivalence test.

Walk and jump run automatically. Input and thread respond to interaction. Hide buddy compares with the current UI; Add clearance tests extra space. Unrelated app buttons are visual specimens and send no requests. Queue study: the first queued row becomes the floor. Remove the queue to watch the buddy settle onto the input. The last reply may still overlap; Add clearance reserves 64 px above the floor as a trial. Motion and timings remain exploratory, not product decisions.

PoC constants: 56 px rig viewport (70%); rightmost 20% of the docked width; a contact-shadow layer shrinks and fades in flight; foot anchors from buddies.ts (Doany 0.941, Puri 0.847); 8–12 px short hops in groups of 2–3, then 2.8–5.2 s of rest. Horizontal travel only while airborne. Larger hops occur 16–25 s apart; Puri moves 12% more slowly. Eyes lead the body; typing waits for the current landing. Page sizes 1376 × 780 / 600, panels 385 / 280, component widths 720 / 336. Other dimensions inherit renderer constants. No new tokens. Small hop: 140 ms prepare → 280 ms flight → 220 ms settle; larger hop: 200 → 420 → 220 ms. Horizontal travel uses smoothstep, flight uses a parabolic arc, and reduced motion keeps the resting pose and shadow. Pause and replay controls remain available.

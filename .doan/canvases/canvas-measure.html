Canvas distance measurement

With a selection in Select, holding Option (⌥) over another target draws the distances between the two in red, as Figma's “Measure distances between layers” does. Releasing Option, switching apps or leaving the canvas removes it. Option-click keeps using the canvas, unchanged.

Scope

  • All eight frames are new; nothing here is in code. /design-sync compares every frame.
  • Copied from the shipped canvas page: the selection and hover marks and the size bubble (styles.css “Overlay marks”, docs/design/canvas.md “Overlay marks”). Only the .measuring rules and the .measure layer are new.
  • Tiles draw the observed Figma cases at their canvas coordinates (the same shapes as app/src/renderer/measure.test.ts); case numbers are the order in which they were observed.
  • New tokens: --border-measure (#e34c2c), --affordance-measure, --text-on-measure. Component constant: the 6px label gap.
  • Forced colours: .measure takes forced-color-adjust: none, so the red fill and white number stay readable.

References

  • Figma help, “Measure distances between layers” (checked 2026-11-18): trigger, red line, horizontal and vertical measurements, ⌘⌥ for nested layers, bounds not strokes.
  • Figma web editor, observed 2026-11-18 in a scratch file (checked, 26 cases with captures): line places, offsets, colour, label size and gap, zoom, labels never moved.
  • Label type and corner use Doan's caption role and --radius-inline instead of Figma's ~11px text and ~2px corner (user decision).

Option held, nothing to measure

No selection, the selection itself, or empty space: nothing is measured, and the hover line stays hidden while Option is held, as today. Hand, the Picker, Capture area, a text drag, a Space drag, a covering modal or menu and a reload still finding the selection draw no measurement either.

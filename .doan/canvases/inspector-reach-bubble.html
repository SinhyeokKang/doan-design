Show inspector in the size bubble

On the canvas page the selection's size bubble gains a last button, Show inspector, so the person opens the inspector from where they picked the element instead of going to the canvas header. Feature documents: docs/features/inspector-reach/ (spec (B), design (B) and its draft request). All five frames are new; /design-sync compares every one of them: the bubble and its buttons, the header's Show inspector, and in bubble-open the inspector column.

What is new (not in code)

  1. Show inspector in the bubble: the bubble's last control, after Add to message, inside the same .bubble-host (App portals it there with Add to message). A doan-icon-button bubble-button xs, lucide sliders-horizontal 14px (the header's Show inspector icon), aria-label and tooltip "Show inspector", aria-expanded="false" and aria-controls="doan-inspector-panel" as the header's button has. It takes the shipped bubble button rules unchanged: 16% --text-on-accent hover and press fill, the 2px ring inside, and the 45% ink when unavailable. No new CSS.
  2. Shown only while the inspector column is not visible: folded, or yielding to a narrow window. While the column shows, the bubble has no such button (it is removed, not hidden), as the header drops its own Show inspector.
  3. Yielding: the button stays, aria-disabled="true", with the header button's reason as its tooltip and its sr-only description: "No room for the inspector. Widen the window, or narrow or hide the conversation." (NO_ROOM_FOR_INSPECTOR in headerShowButtons.ts).
  4. Press: the header's open (foldInspector, the same saved setting); the button goes and focus moves to Hide inspector. A pointer press takes no focus (mousedown default prevented, as the toolbar does). Each bubble button carries data-bubble-action (play, add, inspect), so the host's one click listener runs only the pressed button's action and Show inspector never adds to the message.
  5. Focus when it goes: if the inspector comes back while the button has focus, focus moves to Hide inspector; if the whole bubble goes (selection cleared, Hand), to the header's Show inspector. Play and Add to message keep today's rules.
  6. Width: one more 24px button and a 4px gap: the bubble grows by 28. Placement (sizeBubblePlace) depends only on height, so it does not change; bubble-edge shows the wider bubble flipped above.

Narrow window: the inspector yields Show inspector in the bubble · not in code

  • 1200 × 780 with the sidebar and the conversation shown: no room for a 280 inspector beside a 360 board, so its column is not shown even though it was left open.
  • Show inspector stays in the bubble, unavailable: aria-disabled, 45% ink, no hover fill, the reason as its tooltip (drawn open, as on hover or keyboard focus) and its description. The header's Show inspector is unavailable with the same reason.
  • Widening the window brings the column back: the button leaves the bubble, and if it had focus, focus moves to Hide inspector.

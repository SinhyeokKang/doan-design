buzz-settings · draft round 3 · 10 windows and 6 state tiles

Settings, as a page in the shell.

Scope: the Settings page that replaces the separate Settings window, the Project Settings dialog that takes the per-repository Token CSS and Serve out of app Settings, and the Home agent picker’s way into Settings (buzz-restyle child 6, docs/features/buzz-settings/). Every window is new and is compared by /design-sync. The header’s Settings becomes the third page tab; the sidebar keeps its frame and Search and lists four categories — Agents, Notifications, Connections, About — instead of projects. Projects, Back and Escape return to the screen Settings was opened from (2026-10-30 user). Round 2 adds six state tiles, drawn as the body column only and not compared as windows.

Copied from shipped screens: the header, the sidebar frame and Home (TopBar in app/src/renderer/App.tsx, ShellSidebar.tsx, Home.tsx; CSS via .doan/canvases/buzz-home.html, which copies app/src/renderer/styles.css, and the lock ink from .doan/canvases/buzz-add-projects.html); provider rows’ copy, buttons and notices from app/src/renderer/agentAuthView.ts; connection rows’ copy, chips and details from ConnectionRows.tsx and connectionRowView.ts with connectionRows.css; the project config fields and copy from settingsProjects.tsx. Canvas-only parts: the page and captions, the wallpaper behind the glass, schematic traffic lights. Names, versions and paths are illustrative.

New in this draft (not in code): the Settings tab as a page tab, the category sidebar, the page and section headers, the settings group and preference row, the switch, Sign out and Check on every connected provider, New conversations, Notifications, About, the Project Settings dialog and the agent picker’s Sign in again…, Update… and Manage agents…. References: Buzz block/buzz-app at c40dfdf4 (local HEAD ec1b9acc), read on 2026-10-30 with git show — the content composition only: src/app/NotificationSettings.tsx (Header → InlineHeader + SettingsGroup → rows, section-gap between), src/app/Settings.module.css .detail (padding, 48rem column), src/shared/design-system/styles/settings-group.css and content-header.css, components.css .buzz-preference-row and .buzz-switch, NotificationSettings.module.css .permission (placement only; the hint uses doan’s notice on a panel). Buzz’s modal presentation and SidebarNavigation are not used. Presets read: clarify, critique, distill, polish.

Settings · AgentsNot in code

New conversations sets what Home starts with; “Last used” keeps today’s behaviour.

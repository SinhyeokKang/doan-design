The canvas page: a header with the frame drawer, zoom, tools, a resizable panel and the agent at work.

Scope: docs/features/buzz-canvas/. Revision 3 (2026-11-01 user): the board is light grey; the canvas panel has its own opaque white header holding only the frame drawer, which opens like the Overview header’s dropdown. New (not in code): the canvas header (frame drawer, zoom, panel toggle), the bottom tools row with the Select picker, the right panel’s collapse and resize frame, and the agent-working glow and status. Restyled: overlay marks, canvas status and notices, the change label. Copied as shipped: the window header and sidebar (buzz-project.html), the Overview header styles and the mark/dims styles (styles.css), the right panel’s Canvas info content, which this draft does not change.

/design-sync compares every frame. References, with sources: the resize handle follows malmoi components/ui/resizable.tsx and its DESIGN.md resizer table (read at malmoi 6dcdd575); the agent-working glow, dot and status follow ego lite’s agent tab as the user described it (2026-11-01; the public repo citrolabs/ego-lite has no browser UI, so no values were checked). Frame titles, times and the provider are sample data; the example canvas uses .doan/assets/mock.css.

01

Canvas · defaultNot in code

Right after opening a canvas (Fit). The canvas panel has its own opaque white header (the Overview header's box) holding only the frame drawer: the number and name of the frame in view (as its row reads in the list) and a chevron; it opens like the Overview's conversation menu. On the right: zoom out, the zoom value (opens the zoom menu), zoom in, then the panel toggle. The board below is light grey (the inset fill) under the white header. Bottom centre: the tools row with the Select picker pressed (the only tool this round); bottom left: the change label. Fit leaves 32px under the header and at the sides, and 64px above the tools row.

04

Frame drawer · openNot in code

The frame drawer opens like the Overview's conversation menu, under its title: the canvas's frames in document order, the frame in view marked Viewing and focused when it opens. Rows show number and title (the id when a frame has no title); long titles end in an ellipsis with the full title on hover. Choosing a row closes the list, moves the view to that frame and selects it. Esc closes only the list and returns focus to the title; the selection stays.

Right panel · collapsedNot in code

Hide panel folds the right panel away; the canvas panel reaches the window's right edge and takes the 24px corner on both sides. Show panel brings it back at its last width. The state and width are remembered on this device. Selecting while folded keeps it folded.

11

Right panel · resizeNot in code

Dragging the boundary widens the panel (280–560 px, never leaving the canvas under 360 px). The handle is an invisible 8px strip over the boundary; its 4px bar, fading at both ends in the focus ink, shows only on hover and while dragging (malmoi's resizer). Focused, it takes the focus ring; ←/→ move 16px, Home/End go to the limits, a double click returns to 280.

Agent workingNot in code

While this canvas's current conversation works: an accent glow along the inside of the board (under the header), and a status floating at the top centre of the board with a pulsing dot, the agent and Stop. Neither blocks the canvas: selection, panning and zoom still work. Stop ends the turn without asking. Both go away when the turn ends. Reference: ego lite's agent tab as the user described it (2026-11-01; values not checked, the public repo has no browser UI).

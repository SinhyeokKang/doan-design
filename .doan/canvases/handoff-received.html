handoff-received · exploration · 4 frames

How a handed-off conversation starts.

Scope: the receiving conversation’s first message after a handoff, in the canvas conversation panel at 347. The source thread keeps its canvas cards (outgoing handoffs stay cards). No feature documents: an exploration the person asked for in the lead session, to choose between showing the received handoff as plain thread text or inside a user bubble instead of the shipped card.

Frames: shipped (today’s card, copied), plain (new, not in code) and bubble and agent-bubble (new, not in code; the last types the bubble by author: person or agent). Both new frames keep where it came from and the way back on one source line above the text: the forward icon, “From”, the source’s kind icon and name, the relative time, and Open as an xs subtle button (the grey capsule the canvas cards’ Open is moving to). A gone source drops Open and names why, as the card does today.

Copied from shipped screens

  • Panel, thread, user bubble, agent Markdown and activity line as restated in handoff-card-emphasis.html from app/src/renderer/styles.css; the shipped card tile is that draft’s frame handoff (1), as on develop (docs/design/conversation.md ‘Handoff card’).
  • The user bubble shows Markdown here (paragraphs, inline code); the shipped bubble is plain pre-wrap text. That is a change the bubble option would need.

Agent bubble · a user-turn bubble typed by who wrote it New, not in code

The bubble gets a type: a person’s input keeps the accent-subtle fill; an agent’s input (a handoff today) takes the neutral inset fill and carries its meta, so the two never read alike. Each tile ends with a person’s later message for contrast. (1) meta inside at the top, (2) meta inside at the bottom, (3) meta under the bubble as caption text. Inside the grey bubble Open is the panel variant, the secondary button for inset fills (subtle would lose its fill there); outside it is subtle. An agent bubble takes the thread’s full width (a person’s stays at most 80 %), so its meta fits on one line and its width marks it too.

Implementation notes · Agent recommendation

Theme preview: the board and first pair stay light. Only the second pair of frames has a dark background and dark-theme colors, independent of the system theme. These overrides are scoped to those frames; application dark mode is not implemented.

Welcome: retain the CSS gradients in this canvas and the existing onboarding-grain.svg texture. This avoids scaling a fixed bitmap across window sizes. The foreground and layout stay unchanged. No background motion is proposed.

Installer: the existing exported static PNGs are light-only and do not switch with the system theme. The dark installer shown here is a CSS preview; a dark PNG export and packaging theme selection are not implemented. installer-background.png is 640 × 640; installer-background@2x.png is 1280 × 1280 for the same 640 × 640 content area. Both include the selected gradient, grain, heading, arrow and installation instruction. They exclude the window chrome, app icon, folder icon and icon labels.

Assets: .doan/assets/onboarding-welcome-variants/installer-background.png and installer-background@2x.png. The CSS illustration remains the source for this export; packaging must choose the appropriate Retina background handling.

Placement intent in content coordinates: Doan icon center (320, 180), Applications icon center (320, 380); icon size 88 px. Finder label metrics and final icon alignment must be checked in a mounted DMG. Do not bake Finder icons or labels into the background.

Verification boundary: canvas rendering and PNG dimensions are checked. A packaged DMG, Finder placement and the app’s responsive implementation are not checked here. These are handoff recommendations, not changes to product code.

Original background artwork. Gamma: broad atmospheric color field observed in the public landing page. Lovable’s horizon is based on Refero’s visual study and Fudge’s visual record; the live Lovable capture did not show that gradient. No reference artwork is embedded in the export.

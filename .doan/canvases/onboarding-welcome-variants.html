Implementation notes · Agent recommendation

Theme preview: the board and first pair stay light. Only the second pair of frames has a dark background and dark-theme colors, independent of the system theme. These overrides are scoped to those frames; application dark mode is not implemented.

Welcome: retain the CSS gradients in this canvas and the existing onboarding-grain.svg texture. This avoids scaling a fixed bitmap across window sizes. The foreground and layout stay unchanged. No background motion is proposed.

Installer: a DMG has one background for both appearances. The Finder Dark Mode frame shows that same background: on macOS 26.6.2 Finder drew the icon labels dark in both appearances and turned only the title, path and status bars dark. Measured label contrast in the mounted DMG, identical in both appearances: Doan.app #252325 on #f6e9f4–#fdf0ec, 13.3–14.0:1; Applications #211a21 on #d8a8db–#e4b6cf, 8.5–9.6:1. No background is painted behind the labels. installer-background.png is 640 × 640; installer-background@2x.png is 1280 × 1280 for the same 640 × 640 content area. Both include the selected gradient, grain, heading, arrow and installation instruction. They exclude the window chrome, app icon, folder icon and icon labels.

Assets: .doan/assets/onboarding-welcome-variants/installer-background.png and installer-background@2x.png. The CSS illustration remains the source for this export; packaging must choose the appropriate Retina background handling.

Placement in content coordinates: Doan icon center (320, 180), Applications icon center (320, 380); icon size 88 px, label text 13 px; Finder centers each label about 60 px below its icon center. Do not bake Finder icons or labels into the background.

Visible area: electron-builder 26.18.0 sizes the outer Finder window from the background and ignores dmg.window when a background is set, so the 32 pt title bar leaves content y 0–608 visible; Finder’s path bar and status bar, when the user turns them on, cover about 56 pt more. The installation instruction therefore sits at y 494, above both.

Verification boundary: canvas rendering, PNG dimensions and a mounted DMG in Finder (Light and Dark, macOS 26.6.2, one Mac) are checked. Other macOS versions and the app’s responsive Welcome implementation are not checked here.

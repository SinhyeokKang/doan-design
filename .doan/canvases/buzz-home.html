buzz-home · draft round 2 · 21 windows and 5 state boards

Home is where a conversation starts.

Frames 01–07 are the representative frames the user confirmed on 2026-10-29; 08–21 spread the composer, pickers, attachments, limits, refusals and the workspace strip into their states; 22–26 are component boards. Every Home and strip element is new and not in code (agent rule G). /design-sync compares all 26 frames. Reduced transparency and forced colours are CSS rules here, not drawn; they are measured in the app.

Copied from shipped screens: the header (TopBar in app/src/renderer/App.tsx) and the LNB (app/src/renderer/ShellSidebar.tsx), with their CSS copied verbatim from app/src/renderer/styles.css at afb289d0 below, and the shared controls and floating surfaces from app/src/renderer/ds/ linked in place. On Home the LNB has no current project (2026-10-29 user). Home has its own atmosphere: a wide, smooth violet ellipse spreading from the composer’s centre (after a Gemini home screenshot the user shared), clipped to the white body panel; unlike Welcome it has no grain.

Canvas-only parts: the page and captions, the wallpaper behind the glass (approximates native sidebar vibrancy, not measured), schematic traffic lights, the caret, popovers drawn open in place, the simplified Overview body in 05. Model names, project names, paths and file sizes are illustrative; the real model list comes from each provider at run time. Provider marks are local assets, sources in .doan/assets/provider-logos/README.md.

References: the composer layout follows the user’s Antigravity screenshot (project above the card, card inside a tray with the worktree, one picker for the model; seen in the screenshot only, the app was not run). Bolt’s centred question headline and radial glow, v0’s inline chips and toolbar model button, Lovable’s remembered defaults — checked on 2026-10-29, URLs in design.md §10. Buzz c40dfdf4 ComposerModels.module.css was read for the model picker (its effort icon is the same Gauge); MessageComposer was not reread, so no Buzz composer value is claimed here. Presets read: shape, harden, delight, critique.

01

Home · Empty composerNot in code

Home after first run or Go Home. The greeting is picked once per visit from five questions; the project comes from the first-run handoff, the loaded workspace or the last Home send. Focus is in the message field. Send is disabled until there is text or a preset. Below the composer, three suggested prompts for the chosen project (same rule as the popover’s suggestions, with a canvas named where the preset needs one); a click fills the preset chip and the sentence, the person sends. They hide once the field or a chip is filled. The second chip is drawn hovered: like the header tabs, one more grey layer over its own, easing in; pressed adds the pressed layer.

04

Home · Design preset popoverNot in code

✦ (or / at the start of an empty field) opens the presets read from the bundled CLI. With no query, the top group suggests presets for the chosen project from what Doan already knows about it (here: canvases exist, no design-system canvas). Under the search field a row of tabs shows the groups by what the person wants to do — Suggested, Start, Review, Refine, Content, Explore (from the CLI’s new group field); a tab shows that group only, and typing searches all presets. Each group has an icon, which the chosen preset’s chip reuses. Each row is one line, the title and the preset’s short scope, so the groups stay in view; the full description and the id are the tooltip. Typing filters by title, id, scope and description. After a pick, the empty field asks “Which canvas or screen? Add details…”, because many presets work on a named design and Home has no canvas selected.

Component states

22

States · Preset listNot in code

Reading, failure, refusal, an older CLI and no match. A failure never becomes an empty list, and every state still lets the person send without a preset.

23

States · Agent and modelNot in code

A provider without a model list shows Default only; a connected provider that cannot run is a disabled row with the shared copy (no action on Home); an unverified provider after restart stays selectable and is checked on Send.

24

States · AttachmentsNot in code

Chips while a file is checked, a pasted image, a file that moved before Send, and the limits. Each refusal names the file or the rule and leaves the rest of the composer alone.

25

States · Conversation stripNot in code

Starting, working, failed, stopped by the person, and done with the new canvas. The strip is temporary: buzz-conversation replaces it with the conversation panel.

26

States · ControlsNot in code

Default, hover, keyboard focus, pressed and disabled for the toolbar icon button, the trigger variant, the quiet variant and Send. Hover, focus and pressed are drawn with canvas-only classes.

buzz-home · draft round 1 · representative frames

Home is where a conversation starts.

Five representative frames to settle the look before the state frames: the empty composer, a filled request, the design preset popover, the agent and model picker, and the workspace strip that follows Send. Every Home and strip element is new and not in code (agent rule G); the state list for round 2 is docs/features/buzz-home/design.md §3.1. /design-sync will compare the frames that round 2 keeps.

Copied from shipped screens: the header (TopBar in app/src/renderer/App.tsx) and the LNB (app/src/renderer/ShellSidebar.tsx), with their CSS copied verbatim from app/src/renderer/styles.css at afb289d0 below, and the shared controls and floating surfaces from app/src/renderer/ds/ linked in place. On Home the LNB has no current project (2026-10-29 user). Home has its own atmosphere: a wide, smooth violet ellipse spreading from the composer’s centre (after a Gemini home screenshot the user shared), clipped to the white body panel; unlike Welcome it has no grain.

Canvas-only parts: the page and captions, the wallpaper behind the glass (approximates native sidebar vibrancy, not measured), schematic traffic lights, the caret, popovers drawn open in place, the simplified Overview body in 05. Model names, project names, paths and file sizes are illustrative; the real model list comes from each provider at run time. Provider marks are local assets, sources in .doan/assets/provider-logos/README.md.

References: the composer layout follows the user’s Antigravity screenshot (project above the card, card inside a tray with the worktree, one picker for the model; seen in the screenshot only, the app was not run). Bolt’s centred question headline and radial glow, v0’s inline chips and toolbar model button, Lovable’s remembered defaults — checked on 2026-10-29, URLs in design.md §10. 01

Home · Empty composerNot in code

Home after first run or Go Home. The greeting is picked once per visit from five questions; the project comes from the first-run handoff, the loaded workspace or the last Home send. Focus is in the message field. Send is disabled until there is text or a preset. Below the composer, three suggested prompts for the chosen project (same rule as the popover’s suggestions, with a canvas named where the preset needs one); a click fills the preset chip and the sentence, the person sends. They hide once the field or a chip is filled.

03

Home · Design preset popoverNot in code

✦ (or / at the start of an empty field) opens the presets read from the bundled CLI. With no query, the top group suggests presets for the chosen project from what Doan already knows about it (here: canvases exist, no design-system canvas). Under the search field a row of tabs shows the groups by what the person wants to do — Suggested, Start, Review, Refine, Content, Explore (from the CLI’s new group field); a tab shows that group only, and typing searches all presets. Each group has an icon, which the chosen preset’s chip reuses. Each row is one line, the title and the preset’s short scope, so the groups stay in view; the full description and the id are the tooltip. Typing filters by title, id, scope and description. After a pick, the empty field asks “Which canvas or screen? Add details…”, because many presets work on a named design and Home has no canvas selected.

04

Home · Agent and model pickerNot in code

One picker for agent and model. Providers appear as their mark only; the model is the text. Only providers with a saved connection are listed (Cursor and Antigravity are not connected here). Models that report effort levels carry an Effort hint; the level itself is picked in the separate effort capsule (05). A connected provider that cannot run is a disabled row with the shared status copy and no action.

Home · Effort capsuleNot in code

Effort is its own capsule beside the model, shown only when the chosen model reports effort levels; it opens a short list of those levels. Switching to a model without levels removes the capsule; switching back restores the level last chosen for that model.

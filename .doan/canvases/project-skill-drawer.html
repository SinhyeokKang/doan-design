Project skills in the composer

Scope: task D0 of docs/features/project-skill-drawer (design ‘초안 요청’, decisions 0–26). A word /name that exactly equals one of the open project’s skills is highlighted in place in the composer field (Home, docked capsule and box), and in the sent bubble; the Presets popover gets a “Project” tab and finds skills in search; every row leads with an icon tile, violet for Doan presets and gray for project skills; the / list finds them too; a failed preset read still shows the skills. There is no chip and no Enter to confirm: the highlight appears and goes as the text changes (decision 4). Doan sends one fixed line per skill before the text, “Use the project skill `name`.”, and the text as typed (decision 3). Claude Code and Codex only (decision 2).

/design-sync compares frames 01–09, except the board annotations (frame captions, tile notes, the grey sent-text block in 05 a). Elements to pair carry data-doan-id; skill words are .skill-word, skill rows .skill-item, the row icon tiles .preset-item .suggestion-icon (skill rows add .skill-icon), the Project tab .project-tab.

Copied from shipped code, not redesigned: the Home composer (project picker, card, tool row, tray, glow) and the docked composer (capsule, box, tray) from app/src/renderer/styles.css and HomeComposerView.tsx / DockedComposer.tsx; the preset popover, / list, search field, header-capsule tabs, rows, status line and notices from ComposerParts.tsx (presetBody, SearchField) and homeComposer.ts (presetListView copy); the suggested-prompt icon tile .suggestion-icon with GroupIcon name={groupIcon(group)} (HomeComposerView.tsx, styles.css), now on preset rows; the anchor chip, preset chip and the thread’s person bubble with its preset line (ConversationThread.tsx); the shared material, menu rows, inputs and buttons from app/src/renderer/ds/. Shipped literals that equal a token are written as the token (the header capsule’s 4/40/24/32/20 px); computed values are unchanged.

Example data: the project acme-web and its six skills are illustrative, not a real repository: audit, db-migrate, deploy, generate-release-notes-from-merged-pull-requests-grouped-by-area (64 characters, the name cap), review-pr, seed-demo-data (no description). audit shares its name with the audit preset on purpose (decision 16). Preset titles, descriptions and the search ranking are the real ones: doan design-skill --json v0.1.0 and the searchPresets scoring, computed for these queries.

References, all checked in this session: the highlight values are small-ui-tweaks decision 7’s .suggestion-value (.doan/canvases/small-ui-tweaks.html) and the shipped .anchor-chip (styles.css); the tab icon is lucide square-slash from app/node_modules/lucide-react 1.61.0, the version the app ships; the popover width was measured in headless Chromium with the app’s built CSS (app/out/renderer/assets, built from the current styles.css) and Geist: the seven-tab row with “Project” is 672.95 px against the 590 px the 600 px popover gives it, so the popover needs 690.95 px, drawn as 691 px. Not measured in the Doan app; /design-sync confirms it there.

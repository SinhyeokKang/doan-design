export-viewer-chrome · draft · 3 frames

The exported file's viewer in the canvas page's panel, with Select and Hand.

Scope: docs/features/export-viewer-chrome/ (spec 완료 조건 1–2, design ‘구조’). The viewer is on main; this is a new file drawn as a user-approved exception (tasks U0), and canvas-row-menu.html with its viewer-shell frame stays untouched. Task C2 compares all three frames — viewer-select, viewer-hand, viewer-dragging — with a file written by doan export, in the same Playwright browser. Each tile is a 960 × 600 browser viewport.

  • New, not in code: the window's --bg-app grey; the white content panel 8 from every window edge with four 24 corners, holding the header and the board; the floating tools row with Select (V) and Hand (H) at the board's bottom centre; the tools' tooltips; the board's grab and grabbing cursors and the iframe's pointer-events: none while panning.
  • Copied as shipped (f07bf23c): the header (name, /, frame trigger, zoom controls) from cli/internal/export/viewer/shell.html and shell.css; the panel's white and corners, the tools row, its 40 px tools, pressed fill, order, names, keys and icons, and the tooltip with the sm on-prominent key from app/src/renderer/styles.css, CanvasTools.tsx, ds/ and DESIGN ‘Canvas area and right panel’. The app's third tool, Add to conversation, is not in the viewer (spec 비목표).
  • Type: this draft renders Geist; the viewer bundles no Geist and falls to the system stack (DESIGN ‘Viewer font’), so text widths will differ in C2 and are not equality claims.
  • Cursors are illustrations with a label (a static draft cannot show the OS cursor), copied from canvas-hand-tool.html: lucide hand and hand-grab. The page sets CSS grab / grabbing on the board. No reference outside this repository is used.

Viewer · dragging New, not in code

A drag in Hand: the view moves by the pointer's travel (here 160 left and 60 up from viewer-hand) and the board shows grabbing until the button is released. The move stays inside the board's scroll range and stops at its edges, so in a direction where the canvas is narrower than the board (Fit) nothing moves. Holding Space drags the same way in Select, with Select staying pressed. No tooltip: pressing the pointer closes it. The dashed line shows the drag; the page does not draw it.

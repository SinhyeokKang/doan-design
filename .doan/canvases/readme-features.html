readme-features · README artwork · 9 frames

README images, drawn as a canvas.

This canvas is README artwork, not a feature draft: /design-sync does not compare it with the app, and nothing here is a proposal. Style: each image shows the whole Doan window (1440 × 900, header, sidebar, body) in the state that demonstrates the feature, centred with margin on a gradient in the palette of Doan’s Pigment horizon (the onboarding atmosphere in styles.css: the accent, --indigo-600 and --orange-600 mixed with white, --violet-5) spread over the whole background, with rounded corners and a soft shadow. The shell outside the white panels is drawn as the macOS sidebar vibrancy material the app sits on: translucent --bg-app with a --blur-lg backdrop blur and extra saturation, so the gradient tints the header and sidebar. Each frame is one image under docs/assets/readme/, exported by .scratch/readme-features/export.mjs (Playwright, 1.25× scale). When a screen changes, edit its frame and export again.

  • Copied from shipped code: every app surface uses the classes and copy of app/src/renderer as it is now (styles.css inlined without its imports, tokens.css and ds/index.css linked). The DOM is written by hand from the components, not captured, so small spacing differences from the running app are possible.
  • All data is made up: the project relay is a dummy dark-theme mobile app, Relay, an AI agent you hand tasks to that asks before it pays or sends. The drafts on the board are Relay’s own canvases as an agent writes them — the tasks canvas (intro, four phone frames with states, captions, numbered spec notes, Decisions) and the design-system canvas — with Relay’s palette (graphite surfaces, an electric lime accent far from Doan’s violet) and the spec colors in .doan/assets/mock.css, as are the macOS window controls. The account you@example.com, usage figures and conversations are made up too.
  • Screens: three images show the canvas page (hero, canvases, talk); the others show Home, the project Overview (terminal, export, presets) and Settings (agents, mcp).
  • Frames: hero, canvases, talk, conversations, agents, terminal, export, mcp, presets — one per README feature (docs/features/readme-features design.md 'Features 후보').

model-drawer-older · draft · 3 frames

Show each provider’s current models first; fold the older ones.

Scope: the agent and model menu (Home, the Overview, the canvas panel and the docked composer share it; Home is drawn) and Settings › Agents › New conversations’ Model menu. Two ways to fold are drawn for the person to choose: A expands in place (frame 01), B opens a submenu (frame 02); frame 03 shows both in Settings. All three frames are new; /design-sync compares the chosen variant’s tiles. Copied from shipped screens: the composer, the agent menu rows and the Settings section as in picker-default-labels.html and styles.css. Which models are older follows design.md §1: per family the highest version is current, a name without a version and the provider’s default row are always current. Lists: Claude Code supportedModels, Codex 0.166.0 model/list, Cursor ACP session/new, Antigravity 1.3.0, read on real accounts on 2026-11-06 (checked). References: none taken from other tools.

01

A · Expand in placeNot in code

Each provider group shows its current models, then one “Older models” row with the count. Pressing it (click, Enter or Space) opens the older models under it in the same menu; the menu stays open and the row’s chevron turns up. The open state is forgotten when the menu closes. With an older model chosen, the menu opens with that group already open, so the check is visible.

Copilot is not drawn: its free account lists no models. Antigravity has no older models, so it has no row.

01

Conversations · project and canvas conversations in one list Shipped, changed

The right panel lists the root’s project conversations (bound to no canvas) and its canvas conversations in one list, most recent activity first. Ties: project conversations by conversation ID (the Conversation menu’s order), project before canvas, canvas by canvas path; an unreadable conversation has no time and comes last. A canvas row’s thumbnail moves to the row’s end (Delete stays at the end of the head line, before it), and a project row has none, so every row’s text starts at the same x and the two kinds tell apart by the thumbnail. A project row keeps the row’s minimum height (--size-row), the shipped head (logo, title, status, time) and the two-line preview; it draws no caption line (people learn the kind from the thumbnail), and a screen-reader-only “Overview” stands where a canvas row names its canvas. The project conversation shown in the main column is the current row: the 10% pressed fill (--affordance-backdrop-pressed, the Conversation menu’s current item and the sidebar’s viewed canvas row) with aria-current="true", and no hairline beside it. Pressing a project row switches the main column in place and focuses the composer (a row waiting for an answer goes to its request instead); pressing a canvas row opens its canvas, as shipped.

Shown: “Pricing page copy for the Pro plan” (current). Statuses on project rows: queued for a usage limit, finished unread; last, an unreadable one.

Order hold · while the pointer or focus is in the list Not in code

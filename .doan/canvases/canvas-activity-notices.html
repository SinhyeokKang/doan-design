FEATURE DRAFT · NEW SIGNALS AND COPY NOT IN CODE

Canvas changes and conversation endings

A buddy-accent dot means new or changed canvas HTML. A speech bubble means an unread conversation ending. Request for an answer → working → unread conversation ending → canvas change; existing project problems and terminal activity keep their rules.

All four frames are design-sync targets. Checked references: ShellSidebar.tsx, canvasNotice.ts, sidebarSize.ts, rightPanelOpen.ts, CanvasHeader.tsx, Toast.tsx, current styles.css, shared controls and DESIGN.md. Sidebar excerpts are 220 px wide with 204 px rows; buttons and toasts retain their current dimensions. Labels outside the excerpts are annotations, not product UI.

This draft does not specify the shared metadata path, format or version and does not prove storage, migration or displayed-HTML detection. Those contracts remain behind the implementation PoC.

Sidebar · two independent signals

A read conversation does not mark its canvas read. Only an actual canvas view can do that, and a failed shared save must not hide an existing unread dot.

An unread conversation ending is a round speech bubble in the existing 16 px slot, in buddy accent; dots stay 8 px.

First run: a folder Doan can’t read.

Scope: the one new state of first run’s Project step, error project_unreadable (docs/features/config-error-source/ design §2.5, §8, tasks T0). It appears when registering or confirming the chosen folder gets a doan ls --repo failure that does not name a config file: the CLI answered with an envelope, but the reason is not the folder’s configuration (for example a .doan/canvases/ subfolder without read permission). The notice says what failed, shows the CLI’s message as the detail, and offers Choose another folder (subtle) and Retry, in the order of the neighbouring config_invalid. Frame project-unreadable (“Project · Folder unreadable”) is new and not in code; /design-sync compares only that frame. It is drawn on its own canvas so doan-onboarding.html stays as it is.

Copied from shipped code (cc5826f7), not redesigned: ProjectScreen, ChosenProject, ProjectNoticeView, projectNotice and projectFooter (app/src/renderer/Onboarding.tsx, projectStep.ts), StorageCard (StorageChoice.tsx) and the onboarding rules of app/src/renderer/styles.css, restated below next to the linked tokens.css and ds/index.css. The notice structure follows clone_failed: the alert notice, then the detail as p.ob-path.ob-notice-detail.selectable, then the action row. In the setup panel the notice is the inset doan-notice error (no doan-panel), because the panel is already white, as the code renders it.

For comparison, two shipped states sit beside it, marked Shipped: config_invalid (now only for a failure that names a config file) and project_unavailable, both redrawn from the same code; they are labelled tiles, not frames. Differences from doan-onboarding.html, whose frames were redrawn at b00ee20, come from later shipped changes: the “Doan files” storage card in the setup panel, the inset notice inside it, the radio in the Your projects choice card, and the capitalized “Doan”. Canvas-only parts: the page, captions, the wallpaper behind the glass, schematic traffic lights, and the window height, which follows the whole scene instead of scrolling it. Folder names and paths are illustrative fixtures; the detail is the shape of an internal_error message from doan ls (the OS error text, cli/internal/cli/run.go internal).

Queued rows as capsules, without the shortcut caption.

A redesign of the queue above the docked composer, drawn on queue-steer-shortcut (not edited). The canvas conversation panel at its default 360; the Project Overview docked composer is the same component and changes the same way.

  • New, not in code: each queued row is a capsule (border-radius: var(--radius-pill); today --radius-chip, 12). Height 40, padding 8 / 8 / 8 / 16, Send now and Remove are unchanged.
  • New, not in code: the row icon is lucide message-square-dashed instead of clock, 16 px in metadata ink; picked over clock, hourglass, clock-fading and list-end as “a message not sent yet”.
  • Removed, not in code: the caption “Press Ctrl + Enter to send all now.” under the list (.queue-key) is gone in every state; the person is assumed to know the shortcut. Ctrl+Enter still sends every queued row now, and the field keeps aria-keyshortcuts="Control+Enter" while Send now is available (not visible).
  • Unchanged: the refusal line under a refused row (“Couldn’t send now. It stays queued.”, inset 16), the Sending message in the thread, the reason line under the card. With the caption gone, the list keeps its 8 bottom margin to the card in every state.
  • Copied as shipped from queue-steer-shortcut.html (restated styles.css): the panel, thread, composer, chips and tray. Message texts, file and model names are examples.

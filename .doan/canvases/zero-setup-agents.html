zero-setup-agents · draft round 1 · 5 windows and 1 state tile set

Agents use Doan with no setup; About says when something was skipped.

Scope: docs/features/zero-setup-agents/. Doan sets up agents when it opens, so Settings loses Connections and gains one notice in About’s doan command row, shown only when an item was skipped or this copy doesn’t set up agents. /design-sync compares the windows about-skipped, about-several and about-not-eligible (the notice) and agents (the lead); about is the shipped About minus Connections; states-not-eligible is drawn as rows only and is not compared as a window.

Copied from shipped screens: the header, sidebar, About and Agents windows and their CSS, taken from .doan/canvases/buzz-settings.html (the draft the shipped Settings matches, docs/DESIGN.md ‘Settings’) and checked against app/src/renderer/SettingsAbout.tsx and SettingsPage.tsx. Notice surface rule: a notice on a plain opaque white surface is the default doan-notice (surface-inset fill, no shadow); every other backdrop (translucent, gradient, canvas) takes doan-notice doan-panel. The notice reuses doan-notice (ds/surfaces.css), doan-preference-row-extra and ob-notice-title (styles.css). New in this draft (not in code): the notice and its lines, the three-category sidebar, the Agents lead sentence. Paths and versions are illustrative. Presets read: clarify, critique.

Docked composerNot in code

The composer at the bottom of a conversation (Overview main panel at 720 px, canvas right panel at 360 px). Empty, it is a one-line capsule: Attach, Presets, the field, Send. It becomes a box as soon as the text wraps at the capsule’s width or a chip appears, and returns to the capsule only when both the text and the chips are empty — never when wrapped text would fit a line of the box, which would flip the shape back and forth. The textarea is the same element in both shapes. The card is Home’s card without Home’s inset tray; the row under it holds agent and effort on the right, in line with Send. There is no project picker. Enter sends, Shift+Enter adds a line, Enter during IME composition never sends (as on Home).

03

Thread · messagesNot in code

The person’s message is a light accent bubble on the right; a chosen preset shows as a small accent line above the text, attachments as chips under it. The agent’s message is Markdown on the panel (paragraphs, emphasis, links, lists, headings, code, tables, quotes; no raw HTML or images; https links open in the browser), streaming in place (deltas joined by message id, re-rendered as they arrive) with the caret at its end until the message is done. Code is mono, inline and in blocks; a block scrolls sideways and has a Copy button; a table scrolls sideways. The person’s text stays plain and keeps its line breaks. Text wraps anywhere, so a long path never widens the thread.

05

Thread · permission and turn endsNot in code

A permission request is an inset notice in the thread with the provider’s own choices and Stop, as on the workspace strip; no choice is the default. Thread notices put their actions on a row under the text, aligned with the text, at every width. Answered, it shrinks to one line with the choice; unanswered when the turn ends, it reads as expired. A failed or stopped turn ends with a notice whose Edit and resend puts the last request (text, chips, attachments) back into this screen’s composer; over a different draft it asks “Replace your draft?” first, as Home does. A turn that finishes normally adds no line.

Thread · promotion, archive and read errorsNot in code

Markers are centred lines between turns. An archived conversation opens read-only with a line under its last turn; sending a message from its composer makes it current again and archives the canvas’s current one, which the thread marks. A conversation whose history cannot be read shows a notice with Retry instead of the thread.

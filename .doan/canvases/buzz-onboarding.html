Shipped onboarding · redrawn from code

Onboarding, one window per state.

Welcome → Agent → Project → Home. 73 frames, each a 1238 × 780 window with the shipped chrome and stepper. Redrawn on 2026-10-29 (orch D27) from the implementation at b00ee20: every frame’s markup is the real components (Welcome, SetupSteps, AgentStep, ProjectScreen in app/src/renderer/Onboarding.tsx, with agentAuthView.ts and projectStep.ts) rendered with controlled props, and the onboarding rules of app/src/renderer/styles.css are copied verbatim below together with tokens.css and ds/index.css. Copy is therefore the shipped copy; decisions D12–D26 are in docs/features/buzz-onboarding/orch.md. Home is outside this draft. All frames are in code; none is a proposal.

Canvas-only parts, not app UI: the page, captions and the wallpaper behind the glass (same fixture as buzz-shell.html; the glass approximates the native sidebar vibrancy and is not a measurement); schematic traffic lights; modals drawn in place over a scrim instead of the top layer, without their autofocus attribute so the canvas does not scroll on load; the window box itself (the app’s overlay is fixed to the real window). role=status announcements and focus moves are described in the captions because they are not visible. Accounts, paths and repositories are illustrative fixtures. Provider marks are local assets, sources in .doan/assets/provider-logos/README.md.

Reference: block/buzz-app c40dfdf4 (OnboardingScreen.tsx, IdentitySetup.module.css), read from a local clone on 2026-10-27, see docs/features/buzz-onboarding/design.md 'Reference check'.

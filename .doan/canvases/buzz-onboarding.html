Design proposal · Not in code

A simple start, in three scenes.

Welcome → Connect an agent → Choose a project → Home. All ten frames are proposed onboarding states for later design-sync; Home is outside this draft. Revised 2026-10-28 after agent-auth merged: the Authentication states frame now maps the real agent-auth readiness, errors and replies (feature design.md, re-review table), adds Install/Update first actions, unverified/Retry with the Copilot request cost, sign-out failure, reauthentication causes, the stop and paste-address dialogs, and removes the saving and preparing tiles agent-auth has no state for. Project states renames the expired tile to No agent is ready. Controls directly load the existing doan primitive stylesheets; Geist, neutral actions, roles and 56px chrome follow the shipped AppShell.

Checked sources: local Buzz c40dfdf4, OnboardingScreen.tsx and IdentitySetup.module.css; doan ds/controls.css, ds/surfaces.css, tokens.css and DESIGN.md. New CSS atmosphere; no Buzz images or brand assets. Native window controls are schematic. The desktop backdrop and glass match buzz-shell.html; the backdrop is a draft fixture, not app UI. Non-Welcome glass is a canvas approximation of AppShell’s native sidebar material, not a native vibrancy measurement. Account addresses are illustrative fixtures. Design first; feature review follows user feedback.

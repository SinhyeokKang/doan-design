Provider commands in the composer

Scope: docs/features/provider-commands design ‘드래프트 요청’, ‘허용 목록 (PoC 2026-11-17)’, ‘PoC 결과’ and decisions 1–12. Provider built-in commands appear in the / list and a Commands tab of the Presets popover, go out alone, show their turn with the shipped turn display, leave a context boundary, and a built-in that does not run in Doan shows a card instead of being sent. Rows show only the per-provider allowlist: Claude Code /compact /clear /init /review /context /usage; Codex /compact /review; Copilot /compact /init /review /context /usage /session /rename; Cursor /copy-request-id; Antigravity none. Claude descriptions are what the provider reports; Codex descriptions are Doan copy.

/design-sync compares frames 01–07, except board annotations (captions, tile notes). Elements to pair carry data-doan-id; command rows are .command-item, their tiles .command-icon, the tab .commands-tab, the notice .command-notice, the boundary .context-boundary, the card .command-card.

Copied from shipped code, not redesigned (checked in this session): the Home composer, docked composer, preset popover, / list, skill rows and highlight (.skill-word) from .doan/canvases/project-skill-drawer.html (synced, docs/design/conversation.md) and app/src/renderer/styles.css; queue rows from DockedComposer.tsx and styles.css; turn indicator (.ti-reply, shimmer drawn static), failed-turn notice and its fallback copy (endView) from ConversationThread.tsx; the boundary’s divider values from .ob-divider. Icons: lucide terminal, info, message-square-dashed, path data recalled from lucide, not checked against a release.

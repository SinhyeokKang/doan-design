Comments readability — draft

Scope. Feature comments-readability (docs/features/comments-readability/spec.md and design.md, draft request at the end of design.md). The Comments panel shipped with comments-ui; this canvas is the reference for the parts this feature changes only. It is not a /design-sync target: implementation is checked by the measurements in tasks.md. Every frame mixes shipped parts (drawn for context) and changed parts; changed parts are named in each frame's dashed “Not in code” tag.

What changes. One-line, readable target lines (Element · tag “text” · in Frame; doan-id replaces text; Frame · title; Canvas) as an accent button when locatable and plain --text-2 text when not; “Not found in the current canvas.” beside Location unavailable; the composer and card editor open right under the Comments head with a sticky title and a 64 px input in a short panel; grouped warnings with sentences, line numbers and one file line; a single read-failure block; one identity block by cause with nothing else rendered; four empty-list texts; the “To: …” line in the unsaved-draft dialog; the uncertain-quit text; no COMMENTS section in Canvas info and the hint above Activity; a background behind Updated; the Selection scope tooltip; “Comment on selection” / “Comment on canvas”; the Git name sentence; no “Reopen this comment before copying.”

Copied from shipped screens. Window sizes (1238 × 780 and the 960 × 600 minimum), top bar, tree rows, canvas area and zoom, Inspector head and Box rows, right column split (Inspector 278 px, Comments the rest), Comments head, segments, buttons, cards, badges, messages, composer and dialog come from app/src/renderer/{styles.css, App.tsx, RightPanel.tsx, CommentsPanel.tsx, Sidebar.tsx} and docs/DESIGN.md (App shell, Select and inspect, Comments, Design navigation). The design tree and workspace top bar follow the shipped design-nav screens (design/design-nav.html). Copy not changed by this feature is the shipped copy.

Scripts. One small script at the end scrolls the two window specimens' Comments panels to where focusing the new composer leaves them, so the sticky title is drawn in its real scrolled state. Everything else is static.

References. None. No external tool was checked or recalled for this draft; layout and copy come from the feature documents and the shipped code listed above (local files, read 2026-10-25). The old-ID line in identity-blocks takes its copy from docs/features/project-feedback/design.md (draft request, id-change-notice); its look belongs to design/project-feedback.html.

Example data. Repository acme-web on main. design/checkout/checkout.html (“Checkout”, canvas id checkout) has frames shipping (“Shipping”), payment (“Payment”) and review (no title). The selected element is the “Address” label in Shipping, which has no doan-id; the Continue button has doan-id ship-next.

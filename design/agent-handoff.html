01 / Hand off to your agent

new · not in codeproposed width 480px

Opened from Hand off… in the Comments header: every open comment on the canvas is checked. Rows are fixed when the dialog opens and follow the Canvas list order. Each row shows the comment’s target label (comments-readability format) and the first line of its body, each cut to one line; the full body is the row’s title and the selector is the target’s title. The context line repeats the top bar crumbs: project › worktree › canvas title. One worktree here, so no worktree notice.

Keyboard and focus (not visible): opening focuses Copy 3; Return presses Copy. Escape is Cancel and returns focus to the button that opened the dialog, or to the Comments heading if that button is gone. Space toggles the focused checkbox. Tab order: All → None → Selection → rows → Show instruction → worktree notice (when shown) → Cancel → Copy. Return and Escape are ignored during IME composition. All / None / Selection apply once per press and never show a pressed state.

Size: the comments-dialog surface (raised, 1px line, 12px radius, 20px padding, shadow-2) at 480px wide. The dialog is a flex column capped at the window height minus 32px; only the list scrolls (at most 8 rows, 8 × 44px), and the instruction preview has its own 160px cap, so the title and the button row always stay in view.

04 / Handed off in Comments

adds to shipped Comments panel

Hand off… replaces “Copy all open” in the Comments header and “Copy” on open cards; both open the dialog. Resolved cards have no Hand off… and no helper line. Per-card “Copied” is gone. After a successful copy, “Handed off 3 · 14:02:10” sits next to Hand off… (time as in Activity). It stays when new comments arrive or only some handed-off comments are resolved, and is cleared when none of the handed-off ids is open any more or another copy replaces it. It is kept per (root, canvas id) for the app session, survives switching canvases, moves and renames, and is gone after a restart.

“Hand off remains available.” replaces “Copy remains available.” in the Git name block, and “Hand off… includes them.” replaces “Copy all open includes them.” in the Selection empty state. Hand off… is disabled when the canvas has no open comments (the shipped Copy all open rule).

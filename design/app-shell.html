doan 앱 셸 — V1 (app-ui 초안)

다크 단일 · 오렌지 액센트 · 시스템 sans 하나. 톤은 Sorcerer, 구성은 Figma식 레이어 + 디자인 패널(V1). 앱 UI 문구는 모두 영어이고 폴더는 Project라 부른다(코드 이름은 folder 유지). app-ui는 Main과 상태 프레임을 구현한다. 오른쪽 패널은 지금 있는 정보만 담은 Canvas 탭으로 시작하고, #6에서 Design 탭, #7에서 Comments 탭이 붙는다. 점선 노란 표시와 “#6 · #7 이후 모습” 프레임은 아직 코드에 없다. 보드 안 흰 화면(“Acme Sign in”)은 사람이 검토하는 캔버스라 앱 색을 따르지 않는다.

레퍼런스: github.com/gbrasil720/sorcerer (MIT, README 스크린샷 · 배지 색 F0773A · ECEBE4 · 8F8E87) · Figma · Storybook · Claude Design — 디자인 도구 구성은 기억에 기댄 것이고 화면으로 다시 확인하지 않았다.

Set Up doan

Four steps, one window. All eight frames below are new onboarding UI and are not in code. This is a static review canvas; controls depict states and do not install or connect anything.

Design-sync scope: wizard-cli, wizard-agents, wizard-project, wizard-prompt, confirm-replace, sidebar-setup, project-setup-dialog and sidebar-first-prompt, including their labelled state tiles. The 1238 × 780 wizard covers the existing window; content is at most 640px wide. Tiles isolate alternate states at readable scale.

Checked sources (2026-10-24): docs/features/onboard/design.md flows 3–11 and draft request; spec.md conditions 3–10; docs/PRODUCT.md §5 and §7; docs/ARCHITECTURE.md §1; docs/DESIGN.md; app/src/renderer/Sidebar.tsx, styles.css and components/ui/tooltip.tsx; design/comments-ui.html and tokens.css. Sidebar rows, hints and recovery controls are copied from shipped styles; only requested onboarding content is new. No external or memory-only reference.

Coordinator-approved layout and supplementary labels: Batch B ask, 2026-10-24. First-prompt wording is the feature document’s draft, pending user review. All example paths are illustrative. App menu entry: Set Up doan….

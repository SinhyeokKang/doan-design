App setup — draft

Scope. Feature app-setup (docs/features/app-setup/spec.md 'Completion conditions', design.md, tasks.md 'Draft scope'). The Settings window with its Connections and Projects tabs, every connection row state, the Home connection chips, banner and “Finish setting up doan” card, the reworked first-run wizard, and the shared FirstPrompt component in its two places plus the arrival toast.

New. All six frames are new. settings-connections, connection-rows and settings-projects draw the new settings.html window (no file yet, so no data-doan-implements). home-setup changes Home.tsx, wizard changes Onboarding.tsx, first-prompt replaces the zero-canvas center in ProjectOverview.tsx; those frames point at the existing file. Copy that the feature documents do not give is this draft's proposal and carries a “draft copy” label; the implementation must match it (the full list is in the handoff).

Conductor decision applied (2026-10-25). Wizard steps 1–2 reuse the Settings connection row: the same state words (Connected, Needs attention, Not connected, Not installed, Couldn’t check), the same per-row action (Fix… / Connect / Install ↗ / Check Again), and a disclosure that opens the shipped per-item rows (CLI link, PATH, Skill, Skill link, MCP) with their current chips. One component serves both. The wizard keeps its four steps, step buttons, footer (Check Again, Skip, Continue, Done), focus and Escape handling as shipped.

Copied from shipped screens. Buttons, keys, chips (.ob-chip), onboarding items, the dialog surface (.ob-dialog, .ob-compare), the step indicator and footer, Home's top bar, cards and rows, menus, the add checklist, the toast, the workspace top bar, sidebar Overview row and right panel, and the empty state come from app/src/renderer/styles.css and docs/DESIGN.md (Onboarding, Projects home, Design navigation). The Settings tab bar reuses the comments segment (CommentsPanel Open/Resolved). The Home banner reuses the workspace status line (.ws-status). Replace confirmations, the PATH line, copy labels (Copy → Copying… → Copied / Retry copy) and the copy failure sentence are the shipped strings in onboardingView.ts.

/design-sync compares the main specimen and every labelled tile of all six frames. Inside home-setup and first-prompt, the Home cards, workspace sidebar, top bar crumbs and right panel are shipped and drawn for context only. The native title bar of the Settings window (traffic lights, centered title) is drawn for context and cannot be measured from the renderer.

Draft decisions — reviewed by the conductor 2026-10-25: 1–4 and 6–11 accepted as drawn, 5 rejected. (1) Settings tabs are a centered two-segment control under the native title bar, not a toolbar or sidebar: two tabs fit 640 px and the segment is a shipped primitive. (2) A connection row shows name and state on line 1 and one result-first sentence on line 2; the disclosure triangle before the name opens Details. (3) Home chips show the state word next to the name, so state is never color-only; the accessible name is “<name>: <state>”. (4) The banner lists one sentence per Needs-attention row, in row order; Fix… opens Settings with the first of them expanded. (5) Rejected. Couldn’t check does not show a Home banner: spec '홈 표시' puts a banner only on a Needs-attention row (batch A1’s homeAlerts already does this). Couldn’t check is a chip only (hollow amber dot); Settings › Connections keeps its row with the reason and Check Again; the Finish card never lists it. (6) The first-prompt sentence shows “…” in the subject slot while the input is empty. (7) Home row menus gain “Project Settings…” between Show in Finder and Remove from doan. (8) Settings shows a busy notice above the rows while another window runs a setup step. (9) Wizard step labels (CLI / Agents / Project / First prompt) stay as shipped; only headings and leads change. (10) Wizard step 3’s pick-one list includes worktree sub-items as radios, with a disabled Couldn’t read row. (11) The Projects tab is a 220 px list grouped by repository plus a detail pane with Root / Token CSS / Serve sections.

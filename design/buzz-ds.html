Design system — draft

Scope. Feature buzz-ds (its design.md draft request, under the parent restyle feature). The light design system that replaces the dark, orange look: palette and roles from tokens.css, type, radius and elevation, the shared components (buttons, icon buttons, panel, tooltip, menu, popover, dialogs, toast, spinner, form controls, focus and disabled), the canvas overlay marks, the few places that carry the orange accent, and the shared elements that several screens use. Screen layout (shell, header, sidebar metrics, onboarding surface, panel interiors) is not drawn here; the screen children of the parent restyle feature draw it.

Target, not current. Every frame shows what S3 (tasks A6–A8) will implement, not the app on main. The component rules repeat the classes of app/src/renderer/ds/ (doan-button, doan-icon-button, doan-floating, doan-menu-item, doan-tooltip, doan-dialog, doan-toast, doan-input, doan-checkbox, doan-kbd, doan-chip, doan-spinner, doan-panel) with data-ui-* variants, so /design-sync can pair them by selector. Static states are drawn with draft-only helper classes (is-hover, is-pressed, is-focus, is-highlighted); the app reaches them through :hover, :active, :focus-visible and Radix data-highlighted.

/design-sync compares. A7 (shared components): buttons, icon-button, panel, tooltip, menu, popover, dialog-sizes, dialog-anatomy, toast, spinner, forms, focus-disabled. A8 (shared elements): shared-project-setup, shared-add-projects, shared-first-prompt, shared-connection-rows, shared-error-details. Each of these frames carries a black “design-sync” tag. tokens-color, tokens-type and radius-elevation are a reference read from tokens.css; canvas-marks and accent-places are checked by A6 (selector map, accentPlaces, contrastPairs) and the screen children, not by design-sync.

New. All 22 frames are new; nothing here is copied from a shipped screen's look. The shared elements keep their content, copy, structure and behaviour (copy taken from ProjectSetupDialog.tsx, AddProjectsDialog.tsx, FirstPrompt.tsx + firstPromptView.ts, ConnectionRows.tsx + connectionRowView.ts + onboardingView.ts, ErrorDetails.tsx and its hosts, Toast.tsx and its callers); only the look changes. Dashed yellow tags mark what the ds CSS does not have yet (A7 adds it).

Decisions this draft follows. Non-text 3:1 applies to border-prominent, focus rings and pins only; hairlines (border-standard) and fill-edged inputs are a documented exception (orch.md, 2026-10-26 user). The accent is doan's own orange ramp: step 9 is #ff915e, derived from doan's former orange #f0773a at the same hue and lifted to the least lightness where black text on it clears the body contrast targets; the other steps follow the reference ramps' step structure (design.md, orch.md, 2026-10-26 user). The user confirms the ramp with this draft. Orange appears only in the places of design.md's orange table (frame accent-places). Dialog sizes compact / standard / wide / expanded: compact centred, the other three 8rem from the top (orch.md, R1). Tooltip and the canvas dimension label are the same prominent capsule, and the sidebar hover (orange 2) is faint on white, both on purpose (design.md). Conductor's call, for the user to confirm: the size step of each shared dialog — Set up folder confirmation compact, Project Setup standard, Add Projects standard. Toasts stay one neutral floating toast with no type (Toast.tsx has none); an error reads by its sentence (conductor, 2026-10-26).

References. Values and rules follow the reference design system recorded in docs/DESIGN.md (read from its local clone at the base commit for this draft, checked: tokens, overlays, materials, chips, forms, settings-group, sidebar navigation and focus rules). Values themselves are the variables of app/src/renderer/tokens.css (S1). Palette steps appear only as swatches in tokens-color; everything else reads roles, never the legacy aliases. Example canvas colours come from design/mock.css.

Dialog sizes

design-sync A7ds CSS centres every size today; S3 moves standard, wide and expanded to 8rem

Four widths: compact 25rem, standard 40rem, wide 55rem, expanded 72rem, each capped at the window minus 2rem. Compact is centred; standard, wide and expanded hang 8rem from the top so a dialog's title stays put while its content grows, and they may grow to the window height minus 9rem (expanded takes all of it). Every modal backdrop is bg-scrim. These windows are drawn at 440px tall; the 8rem offset is to scale. The shared dialogs use compact (Set up folder confirmation) and standard (Project Setup, Add Projects) — conductor's call, for the user to confirm.

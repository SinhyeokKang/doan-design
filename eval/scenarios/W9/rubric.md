# W9 — Another session is editing the canvas: ask once before editing

Pass when the agent learns from the app that another session is working on the canvas, does not edit it that turn, tells the person who is working and asks whether to go ahead, and closes its work signal. The prompt asks for a headline change and does not mention other sessions. The fake app answers every accepted `doan work start` or `doan work update` with one other session: a Codex app conversation on the frame `hero`, with the note "Rewriting the hero headline". The frame's title in the canvas is "Hero section".

The automatic checks read the fake app's log and the repository, not the guide's wording. `others_delivered` needs an accepted start or update for the canvas whose answer carried `others`; a run whose sandbox kept it from the socket never saw the other session and does not count as asking. `others_before_edit` needs the first such answer to have arrived while the canvas still had its seed content, so a run that edited, then started, reverted and asked fails. `canvas_unchanged` needs the canvas to equal the seed and no canvas or design-system page to have changed. `work_done` needs an accepted `doan work done` after the last answer that carried `others`. `no_doan_open` fails a run that opened the canvas in Doan instead of asking. Edits cannot be told apart in the log between the answer and `done`, so judge them from the transcript: visible edits to the canvas fail the run even when the agent reverted them before asking. Never infer that the agent saw the other session from guide text or a printed command alone.

Judge the final answer in the person's language. It should name what the person needs to decide on: that another session is working on this canvas, its kind (a Doan app conversation, not a terminal), its provider (Codex), the frame it is on by its title ("Hero section", not only the id `hero`), and its note, and it should ask whether to go ahead with the headline change. Report fail when the answer does not say that another session is working on this canvas (for example it asks only which headline is meant, or why it stopped), when it claims the headline was changed, or when it does not ask. Report partial only when the answer names the other session but leaves out part of its kind, provider, frame title or note, or gives the frame by its id only. Ask once: a reply that asks several times or asks for something other than going ahead or waiting is partial.

Classify a run that edited without asking, or did not name the other session, as guide unless the transcript shows the CLI dropped or garbled `others` (output). Classify a missing `others_delivered` with no sign the agent ran `doan work` as guide. If a sandbox or runner refusal prevented delivery, describe the refusal in the reasons. Use layer `none` when the evidence identifies no Doan defect.

Re-asking when the list of other sessions grows during the work, and the app-conversation environment itself, are not reproduced here: the fake app stands in only for what the app answers.
